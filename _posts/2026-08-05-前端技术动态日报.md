周二好！昨天（8 月 5 日）前端工具链迎来新一轮发布潮——Vue 3.5.41、Node.js v26.7.0、Nuxt 4.5.2 同日更新，pnpm 12 发布首个 RC 版本，Rolldown 1.2.3 持续迭代，React Native 0.87.0 进入 RC 阶段，工具生态热度不减。

### Vue 3.5.41 发布：稳定版持续迭代

Vue 3.5.41 是最新的稳定补丁版本，持续修复并优化核心功能。与此同时，Vue 3.6.0 的 RC 版本也在推进中（当前为 rc.2），预示着下一代 Vue 的正式发布日益临近。开发者可关注 CHANGELOG 了解具体变更。

_来源：[GitHub Release](https://github.com/vuejs/core/releases/tag/v3.5.41)_

### Node.js v26.7.0 发布：新增 Perfetto 追踪支持

Node.js v26.7.0 是 Current 分支的最新版本，带来了多项新特性：crypto 模块支持通过 STORE 加载器加载私钥、根证书更新至 NSS 3.125、lib 新增 Perfetto 追踪支持（性能分析利器）、module 实现了 `Symbol.dispose` 的 ModuleHooks 支持、test_runner 新增 `--test-coverage-include-all` 参数。这些改进进一步强化了 Node.js 在企业级场景的可观测性与安全性。

_来源：[GitHub Release](https://github.com/nodejs/node/releases/tag/v26.7.0)_

### Nuxt 4.5.2 发布：多项性能优化

Nuxt 4.5.2 是 4.5 系列的最新补丁版本，重点在于性能提升：跳过未变更生成文件的重写、使用懒加载导入加快解析速度、复用未变更结构的 app 与组件扫描等。修复方面涵盖了 Vite 客户端清单路径解析、islands 内链接的客户端导航、动态路由参数类型生成等问题。Nuxt 开发体验持续打磨。

_来源：[GitHub Release](https://github.com/nuxt/nuxt/releases/tag/v4.5.2)_

### pnpm 12 RC 0 发布：sudo 运行保护与安全加固

pnpm 12 发布首个 RC 版本，带来重要变更：通过 `sudo` 运行 `pnpm setup`、`pnpm self-update` 或修改全局安装的命令现在会直接报错（`ERR_PNPM_SUDO_NOT_SUPPORTED`），而非静默操作 root 用户目录，这避免了权限混乱问题。同时修复了 `file:` 依赖源目录变更后未重新复制的问题，并改进了对 Windows 风格路径分隔符的处理。

_来源：[GitHub Release](https://github.com/pnpm/pnpm/releases/tag/v12.0.0-rc.0)_

### Rolldown 1.2.3 发布：内存与性能持续优化

Rolldown（基于 Rust 的 Rollup 替代品）发布 1.2.3，重点在性能：减少构建最终阶段的内存占用、优化 chunk 命名时的导出名构建方式。修复了 dev 模式下 watch 注册失败导致批次中断的问题，并移除了已弃用的 `watch.notify` 选项。工具链 Rust 化浪潮中，Rolldown 正快速成熟。

_来源：[GitHub Release](https://github.com/rolldown/rolldown/releases/tag/v1.2.3)_

### Rspack 2.1.8 发布：前端构建工具迭代

Rspack 2.1.8 于昨日发布，持续优化基于 Rust 的 Webpack 替代方案。Rspack 凭借 Rust 的性能优势，在大型项目中展现出显著的构建速度提升，成为 Webpack 迁移的重要选项。

_来源：[GitHub Release](https://github.com/web-infra-dev/rspack/releases/tag/v2.1.8)_

### React Native 0.87.0 进入 RC 阶段

React Native 0.87.0 发布了第四个 RC 版本（0.87.0-rc.4），预示着新版本正式发布在即。作为跨端移动开发的主流框架，React Native 持续推进新架构的全面落地，鸿蒙适配（ohos_react_native）也在社区推动下稳步前行。

_来源：[GitHub Release](https://github.com/facebook/react-native/releases/tag/v0.87.0-rc.4)_

### SvelteKit 3.0.0-next.14 发布：框架持续演进

SvelteKit 发布 3.0.0-next.14 版本，配套的 `@sveltejs/package`、`@sveltejs/enhanced-img`、`@sveltejs/adapter-static` 等包同步更新。Svelte 生态在 2026 年继续保持活跃，编译时优化与运行时轻量化的理念吸引着越来越多开发者。

_来源：[GitHub Release](https://github.com/sveltejs/kit/releases/tag/@sveltejs/kit@3.0.0-next.14)_
