8月17日，前端与开发者生态迎来戏剧性一天：DeepSeek V4 系列 API 峰谷定价正式生效、GitHub 遭遇大规模宕机数小时、Cursor 趁势推出内置代码托管平台 Origin。以下是详细动态。

### DeepSeek V4 系列 API 正式执行峰谷定价：V4-Pro 结束测试转正商用

8月17日 0 时起，DeepSeek V4 系列 API 正式执行全新定价策略，V4-Pro 同步结束测试阶段，全面转为正式版商用服务。新定价取消统一计费模式，改为「算力错峰分级计价」：高峰时段（北京时间 9:00-12:00、14:00-18:00）价格直接翻倍，空闲时段定价为高峰时段的一半。V4-Pro 高峰时段输出价格达 27 元/百万 tokens，V4-Flash 输出价格由 4.5 元调整为 9.0 元（高峰时段）。DeepSeek 官方建议开发者错峰调用以降低成本，这一首创的峰谷计费模式有望成为大模型 API 定价的新范式，对依赖 DeepSeek 的 AI 编程工作流成本规划产生直接影响。

_来源：[企鹅号 - DeepSeek-V4系列API正式调价](https://so.html5.qq.com/page/real/search_news?docid=70000021_4596a825c5241752)、[企鹅号 - DeepSeek-V4系列API实行峰谷定价](https://so.html5.qq.com/page/real/search_news?docid=70000021_7716a82725193365)_

### GitHub 突发大规模宕机：PR、Issue、Actions 全受影响，历时大半天恢复

8月17日，全球最大代码托管平台 GitHub 遭遇大规模宕机，PR、Issue、Webhooks 和 Actions 等核心功能均受到不同程度影响，官方状态页一度显示多个服务处于故障状态。此次宕机持续大半天时间，对全球开发者协作产生了显著影响，大量 CI/CD 流水线中断。GitHub 官方在事件后表示正在调查根本原因。此次事件再次引发开发者社区对代码托管平台单一依赖风险的讨论——当全球开源协作的基础设施出现故障时，整个软件供应链都会感受到冲击。

_来源：[企鹅号 - GitHub平台突发宕机](https://so.html5.qq.com/page/real/search_news?docid=70000021_8866a83206c61552)、[企鹅号 - GitHub昨夜大规模宕机7小时](https://so.html5.qq.com/page/real/search_news?docid=70000021_5596a83cecd10452)_

### 戏剧性反转：Cursor 宕机当日推出内置代码托管平台 Origin

就在 GitHub 基本控制住宕机局面之际，Cursor 火速推出内置代码托管平台 Origin——一个直接集成在 Cursor 编辑器中的代码托管服务，位于新增的「Codebase」选项卡中。Origin 于当天开启早期测试版，面向所有付费套餐用户开放（选择退出的企业组织除外），允许开发者直接在 Cursor 中新建、克隆和推送项目，无需离开编辑器即可完成代码托管全流程。作为「面向 Agent 打造的代码托管平台」，Origin 针对 AI 编码智能体重新设计了代码仓库工作流，被视为对 GitHub 200 亿美元护城河的直接挑战。Cursor 在刚被 SpaceX 600 亿美元收购后即推出此产品，战略意图明显：构建从模型到 IDE 到代码托管的完整 AI 开发闭环。

_来源：[企鹅号 - Cursor推出内置代码托管平台Origin](https://so.html5.qq.com/page/real/search_news?docid=70000021_2786a8396ff23752)、[企鹅号 - Cursor上线Origin为Agent重建GitHub](https://so.html5.qq.com/page/real/search_news?docid=70000021_2896a83bf1a84352)_

### Qwen3.8 生态再进一步：MediaTek 宣布 Day-0 支持，端侧 AI 编程加速

8月15日，MediaTek 宣布与 Qwen 持续深化合作，随着 Qwen3.8 发布，天玑汽车座舱平台 C-X1 及最新天玑旗舰移动芯片已实现 Day-0 支持，将新一代大模型能力更快带到手机和汽车等终端设备。此前 Qwen3.8-27B 已以 270 亿参数实现消费级显卡本地部署，如今进一步下沉至移动端芯片，意味着未来 AI 编程辅助能力有望在端侧设备上直接运行，为前端开发者提供随时随地的本地智能编程体验。

_来源：[企鹅号 - MediaTek与Qwen深化合作](https://so.html5.qq.com/page/real/search_news?docid=70000021_8596a82da0f58552)、[企鹅号 - Qwen3.8-27B开源](https://so.html5.qq.com/page/real/search_news?docid=70000021_4486a7fa49925952)_
