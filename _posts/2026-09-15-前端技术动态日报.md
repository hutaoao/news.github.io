今天最密集的是「浏览器 + 安全 + 编码代理」三条线同时推进：Mozilla 和苹果在同一天把 Firefox 156 与 Safari 27 推到用户手上，两个 CVSS 9 分级别的 Node 生态漏洞同日披露，而编码代理这边一天之内有四个版本落地。

### Firefox 156 发布：PDF 查看器启动快 45%，大图内存与 CPU 双降

Firefox 156 于 9 月 15 日进入 Release 通道。这版没有抢眼的新功能，但有三处实打实的性能与稳定性改动：内置 **PDF 查看器启动速度最高提升 45%**；页面显示被缩放的大尺寸 JPEG 时，**内存与 CPU 占用明显下降**（对高分辨率图片密集的网页尤其有用）；macOS 版新增「随系统启动自动打开」，企业策略也同步扩展到 macOS。修掉的问题里有两个值得注意：**启用 DNS over HTTPS 后部分不支持 HTTPS 的站点无法加载**，以及**开启内置 VPN 后完全失去网络连接**——这两个都是能让人排查半天的坑。开发者侧有一条平台改动：`text-box-trim` 现在会使用 `::first-line` 伪元素的字体度量，与其他浏览器和规范对齐。另外 PCWorld 提到，**两个星期后的 Firefox 157 将加入 JPEG XL（JXL）支持**，而目前主流浏览器里只有 Safari 原生支持这个格式。

### Safari 27 随 iOS 27 / iPadOS 27 / macOS 27 正式推送：CSS grid lanes 让瀑布流回归原生

苹果在 9 月 14 日晚（北京时间 9 月 15 日凌晨）一次性推送 iOS 27、iPadOS 27、macOS 27、watchOS 27、visionOS 27 正式版。**对前端工程师来说，真正重要的是 Safari 27 带来的三条平台能力**：一是 **CSS grid lanes**，可以用原生 CSS 写经典的瀑布流（masonry）布局，不再依赖重型 JavaScript 库；二是 **HTML 3D 模型元素走出 Vision Pro 独占**，网站可以在 iPhone / iPad / Mac 上直接渲染可交互的 3D 模型，Vision Pro 用户还能进入沉浸式环境；三是工程侧的大扫除——苹果重写了沿用二十年的布局代码，自去年秋季以来推了 **1000 多个修复**，其中一条专门解决「用户输入需要额外数据位的较新 emoji 时网站崩坏」的问题。AI 能力则集中在标签管理上：Safari 27 能按主题自动整理打开的标签页、用自然语言监听网页变化（降价、补货）并通知、以及**用一句描述直接生成自定义扩展**（无需 Xcode，也能同步到 iOS）。这条更新在 HN 上拿到 619 分、711 条评论，讨论主要围绕 Siri AI 首发仅英语、国行机型无缘 Apple Intelligence 等区域限制展开。

### proxy-addr 曝 CVSS 9.1 漏洞：一个写错的前缀长度能让 IP 白名单彻底失效

9 月 15 日披露的 **CVE-2026-90711** 值得每个 Express 用户立刻检查。`proxy-addr` 是判断反代后客户端真实地址的底层模块，`Express` 的 `req.ip`、`req.ips` 和 `trust proxy` 都建立在它之上。在 1.1.0 到 2.0.7 中，**如果信任子网用 IPv4-mapped IPv6 记法但前缀长度写成 IPv4 的大小**（例如写 `::ffff:10.0.0.0/8` 而不是正确的 `::ffff:10.0.0.0/104`），模块不会报错，而是编译出一个前导位全零的掩码，**结果匹配全部 IPv4 地址**。后果是 socket 对端在第 0 跳就被判定为可信，任何未认证客户端都能伪造 `X-Forwarded-For`，从而绕过基于 IP 的访问控制、限流、地理位置限制与审计日志——这是一个自 1.1.0 引入的 **fail-open 回归**，且不会给出任何告警。修复版本是 **proxy-addr 2.0.8**；无法立即升级时，把 IPv4-mapped IPv6 的前缀长度写成至少 97，或改用纯 IPv4 记法（`10.0.0.0/8`）。

_来源：[CVE-2026-90711 记录](https://cert.kenet.or.ke/cve-2026-90711-proxy-addr-vulnerable-ip-spoofing-ipv4-mapped-ipv6-trust-subnet)｜[IONIX 威胁中心分析](https://www.ionix.io/threat-center/cve-2026-90711)_

### moment CVE-2026-17495：非字符串对象绕过 locale 路径穿越防护

同为 9 月 15 日披露的 **CVE-2026-17495**（CVSS 5.9）影响 moment 2.29.2 至 2.30.1。问题出在 `moment.locale()` 的防护逻辑「假定输入一定是字符串」：**传入一个 `match()` 方法能满足检查、但 `toString()` 返回穿越路径的对象**，就能把攻击者可控的路径片段送进内部的 `require()` 调用。这是对 2022 年 **CVE-2022-24785** 的不完整修复，主要影响服务端把用户输入直接喂给 `moment.locale()` 的场景。修复版本 **moment 2.31.0**；临时办法是调用前先断言输入是字符串。虽然 moment 已进入维护状态，但存量项目里这条调用链仍然不少见。

_来源：[Rapid7: CVE-2026-17495](https://www.rapid7.com/db/vulnerabilities/cve-2026-17495)_

### Cloudflare 一天两条：把「可被搜索」和「不许训练」拆开，并给 Workers 加上粒度权限

Cloudflare 在同一天发了两篇开发者博客。第一篇 **《Have it both ways: stay discoverable in search while disallowing AI training》** 给出了一套新控件，让站点所有者可以把「搜索引擎可发现」与「允许 AI 训练」彻底解耦，配套引入 **Accountable 认定**，并明确这是与 Apple、Google、Microsoft 共同建立的一套共享模型——延续了 9 月 15 日生效的 AI 爬虫默认值翻转之后的政策收口。第二篇 **《Give every teammate and agent the right level of access to your Workers》** 则是真正面向工程团队的能力：**Workers 的访问权限终于可以按单个 Worker 收敛**，四个新角色（Metadata Read-Only、Content Read-Only、Editor、Admin）替代十个遗留角色，三个范围层级（单个 Worker / 单个产品 / 整个开发者平台）可以自由组合。这条的动机写得很直白——CI token 和 AI agent 不该再借用账号管理员级别的权限，只为了部署一个 Worker。已有的十个遗留角色会继续可用且无限期支持，不需要急着迁移；不过 D1、R2、KV 的同类粒度角色还没跟上，跨产品的最小权限流水线暂时只能拼着用。

_来源：[Have it both ways: stay discoverable in search while disallowing AI training](https://blog.cloudflare.com/)｜[Give every teammate and agent the right level of access to your Workers](https://blog.cloudflare.com/tag/developers)_

### Claude Code 2.1.273：MCP 掉线自动重连，remote 会话可以 fork 到后台跑

9 月 15 日推送的 **Claude Code 2.1.273** 官方统计含 4 项新增、15 项改进、30 项修复，是一版密度很高的更新。三个新增能力值得记：**LLM 网关提示头**（`x-claude-code-request-class`、`x-claude-code-agent-type`、`x-claude-code-prev-tool-durations`、`x-claude-code-compaction`、`x-claude-code-context-compacted`，用 `CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` 打开，方便网关侧做路由与成本归因）；**MCP 服务器中途掉线时自动重连，重连彻底失败会给出指向 `/mcp` 的通知**（MCP 相关改动已经出现在最近十个版本中的六个里）；以及**可以把用 `claude --remote-control` 或 `/remote-control` 启动的会话 fork 出来，在本机作为后台会话运行**。修复里最值得注意的是**撤销了 2.1.268 引入的一项检查**——当时它会对权限检查器无法完整分析的 Bash 行（如 `eval`、`env -C`）执行 Read / Edit 的 deny 规则，误伤面太大。另一个容易误判的坑也修了：**上下文计量把 advisor 工具轮次算成真实大小的约两倍**，导致 auto-compact 在大约一半的真实窗口就触发。此外还修了通过 MDM 或 `managed-settings.json` 设置的 `allowManagedMcpServersOnly`、`deniedMcpServers`、`disableClaudeAiConnectors` 被服务端托管设置覆盖的问题。

### Gemini CLI v0.60.0：MCP OAuth 强制 RFC 9207，硬编码的 CrUX API key 被清掉

同一天，**Gemini CLI v0.60.0** 落地（距 v0.59.0 七天），这一版几乎全是安全加固。重点四条：**MCP OAuth 流程强制要求 RFC 9207 的 issuer 标识**（防止授权服务器混合攻击）；**移除 chrome-devtools-mcp 里硬编码的 Google CrUX API key**——把密钥塞进 MCP server 是很多团队都在犯的错；**macOS Seatbelt 沙箱隔离临时目录与设置目录**（沙箱容器里的 settings 目录也被单独隔离）；**扩展修改环境变量时必须先征求同意**，并对可改变运行时行为的变量做净化。此外还加了工作区路径边界检查与符号链接解析、系统级配置路径的权限与属主校验、以及针对 NTFS 8.3 短名（SFN）绕过路径校验的缓解。需要留意的是，**当天晚些时候发布的 v0.61.0-preview.0 回退了上一版的 prompt injection 修复并重新启用更严格的文件系统沙箱边界**，说明这条线还在反复调整。

### TypeSafe 发布 System One Models 与首个模型 Jev：不产生字符串，只输出带校准置信度的决策

9 月 15 日，成立两年、一直处于隐身状态的 TypeSafe AI 公开了 **System One Models** 这一新类别，以及首个模型 **Jev**。创始人 Diogo Almeida 是 OpenAI InstructGPT 论文的共同作者、也是初代 ChatGPT 的署名者之一，他的核心论点是「**模型在对话上超人类已经很多年，自动化到底在哪**」——RLHF 优化的是人类评分者偏好的文本，而生产环境里绝大多数调用其实是软件在问一个问题、需要拿回一个类型化答案。Jev 的做法是**放弃字符串生成，改为并行采样一次返回全部类型化问题的概率分布**，因此按构造不可能产生类型错误或幻觉，且每个决策都附带校准过的置信度，让调用方决定何时自主行动、何时升级给人。定价是 **输入 $0.042 每百万 token、输出免费，端到端 70–500 毫秒**，官网宣称在自身 System One 任务上比前沿 LLM 快 193.6 倍、便宜 444.6 倍。需要保留的态度是：**没有开放权重、没有独立评测、只能通过 waitlist 获得早期访问**，且官方承认评测的参考答案取自 GPT-6 Astra 与 Claude Fable 5.1 的平均输出、工作流由自家模型能力团队构建——「不可能幻觉」是关于格式的保证，不是关于正确性的保证，校准曲线在分布漂移下是否成立才是要害。

### shadcn/lint 发布：把设计系统变成编码代理能自查的规则

shadcn 团队推出了 **`@shadcn/lint`**，一个「agent-first」的 Tailwind 设计系统 linter。它要解决的具体问题是：TypeScript 能限制对象属性，但**对 Tailwind 类名字符串提供不了任何语义指导**——agent 被拦住之后往往不会改用正确的 variant，而是绕出一个更复杂的写法。这套 linter 用六条规则（`no-restyle`、`no-raw-colors`、`no-arbitrary-values`、`no-inline-styles`、`no-unknown-classes`、`require-static-classes`）配合组件契约（用正则声明某个组件允许改哪些类），把报错信息写成**可直接执行的修复路径**（「这里该用某个组件的 size prop，而不是随手写 padding」）。它支持 Tailwind v4 项目，可跑在 ESLint 9.30+ 或 Oxlint 1.80+ 上。官方在 150 多次任务跑测里给出的数据是：**编码代理在一轮修正内就能达到零违规；把 lint 反馈一并给模型，修复成本比只给规则低 10% 到 48%**。Vercel CEO Guillermo Rauch 转发时的评论是「**verifiers + skills 才是新的框架**」——同一天 Ultracite 7.12.0 也加入了对应的 opt-in preset。

### Vercel CLI 59.18.0：新增 experiments 命令，并把错误信息改写给 agent 看

### 鸿蒙跨端同日双发：KMP&CMP 首个 Release 与 RNOH 0.84.1

### Cloudflare 另两条基础设施改动：Workflows 状态保留期缩到 7 天、Miniflare v5 面向新 cf CLI

同一天的 Cloudflare 侧还有两条容易被漏掉、但会影响线上排查能力的变动。第一，**Workers Workflows 的实例状态保留期默认从 30 天缩短到 7 天**，只针对 9 月 10 日及之后创建、且属于 Workers Paid 计划的实例——**任何依赖旧保留窗口做审计或回溯调试的工具都需要复查**。第二，**Miniflare v5** 发布，为即将到来的 `cf CLI` 铺路：引入了与 `cloudflare.config.ts` 对齐的新配置形态、移除了废弃的 API（如 legacy alpha D1 绑定）与内部 API（`wrappedBindings`）、移除了内置的模块发现（改由 Wrangler 与 Vite 插件提供模块图）、把本地专用的 `/cdn-cgi` 路由挪到 `/cdn-cgi/local`、并把按资源的持久化选项换成共享持久化根选项。大多数项目通过 `wrangler dev`、Cloudflare Vite 插件或 `@cloudflare/vitest-plugin` 间接使用 Miniflare，官方说明**不需要任何操作**，但如果你直接依赖了 Miniflare 的内部接口，这次就需要改。另外，**Python Workers 现在默认使用 Python 3.14**（Pyodide 314.0.6），适用于兼容日期 2026-09-08 及之后的新 Worker。
