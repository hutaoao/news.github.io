本周前端生态多线并进，TypeScript 正式迎来 Go 语言重写的 7.0 里程碑，ECMAScript 2026 规范正式获批，生态安全与性能两条主线同时推进。

### TypeScript 7.0 正式发布：Go 重写带来 8-12 倍性能提升

微软于 7 月 8 日正式发布 TypeScript 7.0，这是该语言自 2012 年诞生以来最大的一次底层重构。核心变化是整个编译器从 JavaScript/Node.js 移植到了 Go 语言原生实现。微软表示，新版本在完整构建场景下通常能带来 8 倍至 12 倍的性能提升，同时引入了共享内存多线程支持，并显著改善了内存占用。TypeScript 7.0 完全兼容 6.0 语义，现有项目可直接升级。Visual Studio 2026 18.6 Insiders 3 已内置 TypeScript 7 Beta，开发者普遍评价此次升级「感知明显」，在大型项目中类型检查耗时可从数秒缩短至不足一秒。

_来源：[Announcing TypeScript 7 (Microsoft DevBlog)](https://devblogs.microsoft.com/typescript/)_

### React Compiler Rust 移植版正式合并：Meta 主导的 AI 辅助重构

Meta 工程师近日在 GitHub 上正式合并了将 React Compiler 移植到 Rust 的 Pull Request。该项目由 React 核心团队成员 josephsavona 主导，他将其描述为一次「由 AI 主导编码、人类审查」的协作实践。Rust 移植版完成后，Next.js 和 Oxlint 等工具已率先支持集成。此举被视为 React 生态向性能极限推进的重要一步——Rust 天然的内存安全和并发优势有望显著提升编译阶段的吞吐量。

_来源：[React Compiler Rust PR 合并公告 (GitHub)](https://github.com/facebook/react)_

### npm v12 默认禁用安装脚本：供应链安全策略全面升级

npm 官方宣布即将发布的 v12 将默认禁用 `preinstall`、`postinstall`、`prepublish` 等安装脚本，以应对日趋严峻的供应链投毒攻击风险。此前 npm 平台曾遭「沙虫」(Shai-Hulud) 攻击者攻陷维护者账户，短时间内批量投放涉及 300 余个程序包的 600 余个恶意版本，窃取 GitHub Token、云服务密钥等敏感信息。v12 的这一默认策略将倒逼开发者审视依赖包中的自动执行代码，显著提升项目安全性。

_来源：[前端周刊 2026W25 (博客园)](https://www.cnblogs.com/whincwu/p/20713147)_

### ECMAScript 2026 正式获批：JavaScript 第 17 版规范亮点速览

ECMA International 于 6 月 30 日正式批准了 ECMAScript 2026，这是 JavaScript 语言规范的第 17 个版本。本版在多个领域新增了实用方法：`Math.sumPrecise` 用于高精度数字求和；`Iterator.concat` 连接多个迭代器；`Array.fromAsync` 从异步可迭代对象构建数组；`Error.isError` 用于可靠识别错误对象；`Map.prototype` 与 `WeakMap.prototype` 新增键不存在时返回默认值的能力；`Uint8Array` 新增十六进制与 Base64 编码互转方法；`JSON.parse` revivers 新增参数，`JSON.rawJSON` 新增精细控制 stringify 输出中原始值的能力。

_来源：[ECMAScript 2026 正式获批 (腾讯网)](https://new.qq.com/rain/a/20260710A002R500)_

### Deno 2.9 发布：新增 deno desktop 桌面应用开发功能

Deno Land 于 6 月 25 日发布 Deno 2.9，核心亮点是新增了 `deno desktop` 功能，开发者可直接利用熟悉的 Web 技术栈（TypeScript、HTML、CSS）构建原生桌面应用程序，无需切换到 Electron 等第三方方案。新版同时在启动时间、内存占用和 HTTP 吞吐量方面均有改善，Deno 2.8 版本的 Node.js 兼容性已达到 76%。

_来源：[Deno 2.9 发布公告 (企鹅号)](https://so.html5.qq.com/page/real/search_news?docid=70000021_6436a46396093452)_

### 跨端框架持续演进：Flutter-OH 3.35 与 React Native 0.86 最新进展

鸿蒙生态方面，Flutter 框架鸿蒙版（Flutter-OH）与 React-Native 鸿蒙版（RNOH）在 HDC 期间同步跟进上游版本，Flutter-OH 3.35 正式发布，负载与内存占用大幅降低。React Native 0.86 也在推进中，RNOH 社区计划在 Q2 完成 0.84.x 适配版本、Q3 完成 0.86.x 适配版本的发布。Flutter-OH 已非常成熟，社区版支持通过 C-API 直接调用鸿蒙底层能力，为跨端开发者提供了更广阔的选择空间。

_来源：[Flutter、React Native 鸿蒙版全新进化 (企鹅号)](https://so.html5.qq.com/page/real/search_news?docid=70000021_2206a349c4288152)_
