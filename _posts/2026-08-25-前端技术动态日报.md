今天的安全信号格外密集：Next.js 两枚严重 RCE 同日修复、Oracle WebLogic 代理插件漏洞被 CISA 纳入 KEV，与此同时多媒体与框架生态也在稳步推进。以下为 2026-08-25 精选动态。

### Next.js 发布 8 月关键安全更新：两枚严重 RCE 漏洞被修复

Next.js 于 8 月 25 日正式发布 8 月安全更新，版本号为 16.3.3（Active LTS）与 15.5.24（Maintenance LTS），比原定 8 月 26 日提前一天上线，原因是又发现一处上游依赖的严重漏洞。

两枚均为「未授权远程代码执行（Critical）」：其一由底层 libheif/sharp 在处理攻击者构造的 AVIF 图片时触发 RCE（GHSA-2xp9-vwfh-vxw4），修复版本在漏洞修复前暂停 AVIF 优化；其二是 Windows 文件系统托管、且同时使用 Pages Router 与 App Router（未启用 Cache Components）的服务端 RCE（CVE-2026-75604 / GHSA-p293-qw3h-jr36，CVSS 9.0），无可用绕过方案，自托管 Windows 服务需立即升级。

_来源：[Next.js 官方博客](https://nextjs.org/blog/august-2026-security-release) · [更新说明](https://nextjs.org/blog/nextjs-security-release-august-2026-update) · [GHSA-p293-qw3h-jr36](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36)_

### Vercel 确认托管应用已受保护，自托管用户仍需手动升级

Vercel 发布变更说明：托管在其平台上的 Next.js 应用已自动受到保护，无需任何客户操作——AVIF 漏洞曝光后 Vercel 已在其托管的 Image Optimization 服务中禁用 AVIF 处理，而第二枚漏洞仅影响 Windows 文件系统，Vercel 运行时基于 Linux 不受影响。

对自托管应用，官方建议尽快升级到 16.3.3 / 15.5.24；在修复版本中 AVIF 图片将「原样返回、不做优化」，直至上游 libheif 修复后再恢复。

_来源：[Vercel 变更日志](https://vercel.com/changelog/nextjs-august-2026-security-release)_

### CISA 将 Oracle WebLogic 代理插件漏洞纳入已知被利用目录（CVSS 10.0）

8 月 24 日，CISA 将 CVE-2026-21962 加入 KEV（已知被利用漏洞）目录，影响 Oracle HTTP Server 与 Oracle WebLogic Server Proxy Plug-in，处置期限定为 2026 年 8 月 27 日。

NVD 显示该漏洞可由网络侧未授权攻击者利用，CVSS 评分高达 10.0；使用相关反向代理或老旧 Java Web 栈的前端/CDN 团队应优先排查生产、灾备、测试环境是否暴露相关入口，并按 Oracle 公告打补丁或先收缩网络暴露面。

_来源：[稀土掘金 8/25 价值资讯](https://juejin.cn/post/7677489259040964642)_

### Mozilla 计划 Firefox 157 默认开启 JPEG XL 解码

Mozilla 工程师 Timothy Nikkel 发布 Intent to Ship：Firefox 157 将在全平台默认开启 JPEG XL 解码，解码器采用 Google Research 用 Rust 重写的 jxl-rs（替代约 10 万行多线程 C++ 参考实现），并带来渐进式渲染等特性。

这意味着 JPEG XL 正从「尝鲜」进入浏览器兼容性评估期：Chrome 也已提交 Intent（仍处 flag），Safari 早在 2023 年即支持，三引擎有望在 2026 年底前达成跨浏览器支持；图片密集型站点与 CDN 团队可在实验环境并行保存 JPEG/WebP/AVIF/JXL 样本做对比，但不建议立即全量切换。

_来源：[Mozilla Hacks](https://hacks.mozilla.org/2026/08/intent-to-ship-jpeg-xl)_

### BullMQ 6.1.0 移除旧版 API，改用可插拔 IQueueBackend 抽象

BullMQ v6 引入 IQueueBackend 抽象，将 Redis、PostgreSQL、Bun 原生客户端统一为可插拔后端；6.1.0 起移除多个历史 API，包括 Queue#client、Worker#blockingClient、旧版 repeatable jobs 系列方法（getRepeatableJobs / removeRepeatable 等）。

升级前需将遗留的 repeatable job 迁移到 Job Scheduler 模型，且 ioredis 不再作为直接依赖、需显式安装；团队若仍以 ^5 宽松锁定依赖，可能被自动升级到 v6 的「已删除 API」而报错，建议先读官方 v5→v6 迁移指南。

_来源：[BullMQ 更新日志](https://docs.bullmq.io/changelog) · [v5→v6 迁移指南](https://docs.bullmq.io/guide/migrations/migrate-from-v5-to-v6)_

### Astro 7.2.5 / 7.2.6 连续补丁：修复开发模式崩溃与 24 项回归

Astro 于 8 月 24 日连续发布 7.2.5 与 7.2.6：前者打包 24 项补丁，修复内容集合图片解析、Cloudflare 字体 URL 校验、增量构建中过期 CSS 等回归；后者修复开发模式下 server dependencies 被优化时 new FetchState(request) 会失败的问题。

同期 @astrojs/vercel、@astrojs/netlify、@astrojs/mdx、@astrojs/cloudflare 等适配器也一并更新；Astro 当前最新稳定版为 7.2.6，建议通过 npx @astrojs/upgrade 平滑跟进。

_来源：[Astro 发布说明（releases.sh）](https://releases.sh/astro)_

### Vue 3.6.0-rc.5 发布，Vapor Mode 临近稳定

Vue 3.6 进入 RC 第五版（8 月 21 日），Vapor Mode 功能集已完整：基于 alien-signals 重构的 @vue/reactivity 显著提升响应式性能、降低内存占用，并在第三方基准中达到与 Solid、Svelte 5 同级的水平。

本版大幅增强 Vapor 与 VDOM 的互操作与水合可靠性（多根组件、async setup、插槽、片段、KeepAlive/Teleport/Transition 等边界场景），并带来静态模板水合快路径、更激进的 tree-shaking；官方建议先在性能敏感子页面局部采用，稳定版预计今秋发布。

_来源：[Vue Core v3.6.0-rc.5 Release](https://github.com/vuejs/core/releases/tag/v3.6.0-rc.5)_

### Svelte 8 月动态：SvelteKit 3 预览版登场，rsvelte 带来 Rust 工具链

Svelte 8 月更新聚焦 SvelteKit 3 的首批预览版（3.0.0-next.5 ~ next.13），引入 $app/manifest 与 $app/service-worker 新模块、goto 内置浅路由（shallow routing）、refreshAll 取代 invalidateAll，并把 tracing 移出 experimental 命名空间。

社区侧，核心维护者 baseballyama 推出 rsvelte——Svelte 编译器/格式化/Lint/类型检查/LSP 的 Rust 重实现，已在 12,000+ 真实组件上验证；语言工具也迎来零配置 +error.svelte 类型、svelte-language-server 移除 lodash 以加快启动等改进。

_来源：[Svelte 官方博客](https://svelte-website.vercel.app/blog/whats-new-in-svelte-august-2026)_

### 跨端 8 月大版本月：Flutter 3.47、RN 0.87、uni-app x、MAUI Preview 7

8 月跨平台圈迎来结构性大版本：Flutter 3.47（8/12）将 Material 与 Cupertino 从核心 SDK 剥离为独立包（material_ui / cupertino_ui），Impeller 成为 macOS/Windows/Linux 默认渲染引擎；React Native 0.87（8/11）将 Strict TypeScript API 转正、Metro 0.87 内存减半、实验性支持 SwiftPM 与 AGP 9。

此外 uni-app x 5.23 上线 Android 蒸汽模式（Android/iOS/鸿蒙三端覆盖）并新增微信小程序微信 AI 支持；.NET MAUI Preview 7 带来 Passkey 认证与 XAML 增量热重载；KMP 2.4.20-RC 增强 Swift 互操作。

_来源：[稀土掘金 跨平台开发地图 2026年8月](https://juejin.cn/post/7674583645794582563)_
