8月第一周前端工具链迎来密集发布潮，Vite、Astro、Node.js、Deno 齐齐推送更新，同时 TanStack 生态本周集中放出了一批新版。

<!-- more -->

### Vite 8.2.1 补丁版本发布

Vite 团队在 8 月 6 日释出 v8.2.1 小版本更新，修复了 8.2.0 中若干影响开发体验的问题，同时 plugin-legacy 也同步更新至 8.2.3。8 月初的 Vite 8.1 正式引入了基于 Rolldown（Rust 重写版 Rollup）的全新开发打包模式，构建速度进一步提升，本周补丁主要围绕稳定性打磨。

_来源：[GitHub Release - vitejs/vite](https://github.com/vitejs/vite/releases/tag/v8.2.1)_

### Deno 2.9.5 补丁版本上线

Deno 2.9 分支持续迭代，8 月 6 日发布 v2.9.5，修复了 2.9 系列中的若干 Bug。Deno 2.9 在 6 月底带来了实验性的 `deno desktop` 桌面应用开发能力，兼容 Node.js 比例已突破 76%，社区生态稳步扩张。

_来源：[GitHub Release - denoland/deno](https://github.com/denoland/deno/releases)_

### Astro 7.2.0 正式版发布，生态配套同步更新

8 月 6 日，Astro 7.2.0 正式版正式发布，这是 7.x 系列的又一次功能性更新。Astro 7 主打内容优先与 Islands 架构，默认支持 View Transitions，并在构建性能上有显著改善。同日，Astro 官方生态包也迎来批量更新：`@astrojs/vue` 升至 7.0.2、`@astrojs/solid-js` 升至 7.0.2、`@astrojs/node` 升至 11.1.0、`@astrojs/vercel` 升至 11.0.5，分别提升了与主流框架和部署平台的对接能力。

_来源：[GitHub Release - withastro/astro](https://github.com/withastro/astro/releases)_

### TanStack Router 发布 8 月新版，Vue 全家桶同步更新

TanStack 团队在 8 月 6 日推送了 TanStack Router 新版（release-2026-08-06），同步释出的还有一系列 Vue 生态包：`@tanstack/vue-router` 升至 1.170.20、`@tanstack/vue-start` 升至 1.168.36 及其服务端/客户端配套包。TanStack Router 以框架无关的路由设计著称，在复杂单页应用中提供高度灵活的嵌套路由与数据加载能力。

_来源：[GitHub Release - tanstack/router](https://github.com/TanStack/router/releases)_

### Storybook v10.5.7 补丁发布，修复关键缺陷

8 月 6 日，Storybook 释出 v10.5.7，修复了此前版本中的若干 Bug。Storybook 10 是今年的重要里程碑，引入全新的 UI、更快的启动速度以及对 React 19、Vue 3 的全面支持。v10.5 还在组件驱动开发与自动化视觉测试方面做了大量优化。

_来源：[GitHub Release - storybookjs/storybook](https://github.com/storybookjs/storybook/releases)_

### Rolldown 1.2.3 补丁版本发布

Rust 版 Rollup 替代方案 Rolldown 在 8 月 5 日发布 v1.2.3，继续保持高频迭代节奏。Rolldown 已被选为 Vite 8.x 系列的默认打包引擎，其 100% Rollup 插件兼容性让现有生态项目可以零成本迁移。

_来源：[GitHub Release - rolldown/rolldown](https://github.com/rolldown/rolldown/releases)_

### Vue 3.5.41 补丁版本更新

8 月 5 日，Vue.js 核心库发布 v3.5.41 小版本，继续修复 3.5 系列的问题并推进稳定性。Vue 3.5 引入了 Vapor Mode 实验性支持与 Alien Signals 响应式优化，生产级 Vapor Mode 预计在后续版本中进一步成熟。

_来源：[GitHub Release - vuejs/core](https://github.com/vuejs/core/releases)_

### Nuxt v4.5.2 与 v3.21.11 双分支同步更新

8 月 5 日，Nuxt 团队同步更新了 v4 和 v3 两个活跃分支：v4.5.2 和 v3.21.11。Nuxt 4 正在稳步推进中，带来新的内容系统与更强的 TypeScript 支持，而 v3 分支仍在持续维护以满足 LTS 需求。

_来源：[GitHub Release - nuxt/nuxt](https://github.com/nuxt/nuxt/releases)_

### Node.js v26.7.0 发布，v26 成为当前主线版本

8 月 5 日，Node.js 正式发布 v26.7.0（Current），该版本默认启用 Temporal API、搭载 V8 14.6 和 Undici 8，这是 Node.js 26 作为当前主线版本的又一次功能性推进。Node.js 26 在 6 月正式发布，引入了 WebGPU 实验性支持与更快的启动速度，Temporal API 的默认启用是今年最受期待的语言级特性之一。

_来源：[Node.js Blog](https://nodejs.org/en/blog/release)_

### pnpm 12 RC 0 发布，包管理器迈入 12 时代

8 月 5 日，pnpm 正式发布 v12.0.0-rc.0，这是新一代包管理器的重要里程碑。pnpm 12 预计在依赖解析速度与磁盘占用上带来新的优化，同时继续强化 monorepo 场景下的优势。目前已有 v12.0.0-beta.1 ~ beta.4 的完整测试链，RC 版本的发布意味着正式版已近在眼前。

_来源：[GitHub Release - pnpm/pnpm](https://github.com/pnpm/pnpm/releases)_

### OxC 项目 crates 发布 v0.143.0

8 月 6 日，由字节跳动主导开发的 OxC（Oxidation Compiler）工具链再次更新crates版本至 v0.143.0，oxlint v1.77.0 也已在此前一周发布。OxC 用 Rust 重写了 JavaScript/TypeScript 的解析、linting 与格式化工具链，性能远超传统 JS 实现，已被 Vite、Egg.js 等多个项目采纳为核心依赖。

_来源：[GitHub Release - oxc-project/oxc](https://github.com/oxc-project/oxc/releases)_

### TanStack Table v9 正式版释出，多端统一 API

8 月 4 日，TanStack Table v9 正式发布 GA 版本，配套的 `@tanstack/table-core`、`@tanstack/vue-table`、`@tanstack/svelte-table`、`@tanstack/table-devtools` 等均升级至 9.0.0。TanStack Table 9 带来了更统一的跨框架 API 设计，数据管理能力进一步增强，是构建复杂数据表格的首选方案。

_来源：[GitHub Release - TanStack/table](https://github.com/TanStack/table/releases)_

### TanStack Query v5 持续迭代，Solid Query Beta 7 发布

8 月 1 日，TanStack Query 发布新一轮更新，配套的 `@tanstack/solid-query` 同步推出 v6.0.0-beta.7 及相关持久化客户端与 DevTools。TanStack Query 作为前端数据获取与缓存的事实标准，其 Solid 生态支持正逐步成熟，标志着多框架战略的持续推进。

_来源：[GitHub Release - tanstack/query](https://github.com/Tanstack/query/releases)_
