### 微软为 Node.js 推出动态 Windows Runtime 语言投影工具

微软今日发文宣布为 Node.js 开发动态 Windows Runtime（WinRT）语言投影工具，允许 Electron 应用及普通 Node.js 开发者直接通过 JavaScript 或 TypeScript 调用 Windows 原生 API。该工具能自动读取 WinRT API 元数据并生成对应的 JS 接口代码和 TypeScript 类型定义，API 更新时只需重新生成接口代码，无需重新编译原生模块。目前主要面向存储、通知、网络等非 UI 功能，同时也支持调用部分设备端 AI 能力（如文本生成、OCR 等）。这一举措将大幅降低 Node.js/Electron 开发者访问 Windows 原生能力的门槛，对国内大量基于 Electron 的应用开发场景尤为利好。

_来源：[腾讯网 - IT之家](https://new.qq.com/rain/a/20260728A09T6C00)_

### Kimi K3 完整权重上线 Hugging Face，同步开源三项 Infra 技术

月之暗面（Moonshot AI）于 7 月 27 日晚间在 Hugging Face 正式发布 Kimi K3 完整模型权重，并同步公开技术报告及三项关键基础设施技术（MoonEP、FlashKDA、AgentEnv）。Kimi K3 总参数 2.8 万亿（896 专家中激活 16 个），采用 MoE 架构，具备原生视觉理解能力，支持 100 万 token 上下文窗口。此次开源采用修改版 MIT 许可证，开发者可下载、修改并本地部署。对于前端开发者而言，K3 在 SWE-bench 编程评测中的出色表现意味着自托管 AI 编程助手的能力又上一个台阶，尤其适合关注代码补全、代理式编程的团队。

_来源：[腾讯网](https://new.qq.com/rain/a/20260727A0B6ST00) | [TechWeb](https://so.html5.qq.com/page/real/search_news?docid=70000021_6116a6805f929452)_

### OPPO 启动小布 Next 计划，开放行业首个端侧 Multi-Agent 系统内测

OPPO 宣布启动「小布 Next」计划，开放首个端侧 Multi-Agent 协同系统内测。该系统搭载端侧全域记忆系统，支持手机与 PC 跨端联动，可主动记录用户偏好并制定方案。对于前端开发者而言，端侧 Multi-Agent 意味着更复杂的 UI 编排需求和更丰富的端智能交互场景——H5 页面与小布助手的交互方式将大幅扩展。Find X8/X9 系列及一加多款机型可参与内测。

_来源：[腾讯网](https://new.qq.com/rain/a/20260727A07EMK00) | [电脑之家 PChome](https://article.pchome.net/n0/new/1.html)_

### React 19 Compiler vs Svelte 5：虚拟 DOM 延迟基准测试

SitePoint 发布了 React 19 Compiler 与 Svelte 5 的详细基准测试对比文章，聚焦虚拟 DOM 延迟这一核心维度。测试涵盖列表渲染、状态更新、组件树重建等常见场景。文章揭示了 React 19 Compiler 自动优化（useMemo/useCallback 自动生成）在实际场景中的性能表现，以及与 Svelte 5 编译时消除虚拟 DOM 方案的优劣势。这类第三方对比评测对开发者做技术选型具有实用参考价值。

_来源：[SitePoint](https://www.sitepoint.com/javascript/react/)_

### Codeburn 开源：跨 31 款 AI 编程工具的 Token 与费用追踪器

GitHub 开源项目 Codeburn（getagentseal/codeburn）正在开发者社区获得广泛关注，它是一个免费、本地的 AI 编程 Token 用量及费用追踪工具，支持 Claude Code、Cursor、GitHub Copilot、Codex 等 31 款主流 AI 编程工具。它能帮助开发者实时掌握自己的 AI 编程成本，对团队预算管理和工具选型非常有价值。项目采用跨平台桌面应用架构，近期已适配 Microsoft Store 安装渠道。

_来源：[GitHub - getagentseal/codeburn](https://github.com/getagentseal/codeburn)_

### 腾讯 EdgeOne Makers 杀入 Product Hunt 月榜前五

腾讯出品的 EdgeOne Makers 在 Product Hunt 月榜中以 1095 票杀入前五，实际点赞数位列全榜第二。该平台定位为「让开发者像部署网页一样几分钟上线 AI Agent」，大幅降低了前端开发者构建 AI Agent 应用的门槛。对于熟悉 Web 技术栈的前端工程师来说，直接复用前端部署流程来上线 AI 服务，是一次典型的「降维」体验。

_来源：[腾讯网](https://new.qq.com/rain/a/20260727A0BC7300)_

### Comark：高性能跨框架 Markdown 解析器发布

开源项目 Comark（comarkdown/comark）在 GitHub 上发布，定位为支持 Angular、React、Svelte、Vue、HTML 及 ANSI 终端输出的高性能 Markdown 解析器和渲染器。它允许开发者在不同框架中使用同一套 Markdown 渲染逻辑，统一输出格式。对于需要多框架维护内容展示功能的团队来说，这一工具可显著减少重复开发工作。

_来源：[GitHub - comarkdown/comark](https://github.com/comarkdown/comark)_

### JavaScriptBit：MutationObserver 深度实践指南

技术博客 JavaScriptBit 发布了一篇关于 MutationObserver 的深度实践文章，详细讲解如何用原生 API 监控 DOM 变化，涵盖属性变更、子节点追踪和性能优化等技巧，并延伸介绍了在实际项目中的使用场景，如懒加载检测、广告拦截探测和 React 不兼容场景下的回退方案。对于需要精细化 DOM 操作的前端开发者，这是一篇高质量的技术参考。

_来源：[JavaScriptBit](https://www.javascriptbit.com/)_
