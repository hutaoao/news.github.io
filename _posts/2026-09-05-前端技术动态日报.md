9 月 5 日是周六，前端圈本身没多少新东西，但 Hacker News 被一条安全新闻刷屏了：NVD 把 CVE-2026-85046 定性为「影响所有 Chromium 版本」的沙箱逃逸且已在野利用，这对 Electron 与各类内嵌 WebView 的桌面应用是个实打实的长尾风险。另外 Bun 在 1.4.1 发出仅一天后紧急补了 1.4.2，修掉两个刚引入的回归。

### NVD 把 CVE-2026-85046 定性为「所有 Chromium 版本」的沙箱逃逸，HN 361 分刷屏

这条当日冲上 Hacker News 榜首（361 分、204 条评论）。NVD 对 CVE-2026-85046 的描述是：影响**所有**当前 Chromium 版本的沙箱逃逸 + 远程代码执行，且标记为「已在野主动利用」。这不是渲染进程崩溃——沙箱逃逸意味着被攻陷的标签页能在宿主操作系统上执行代码，「点开一个页面」就足以拿下机器。Google 已于 9 月 3 日在稳定通道推送修复（Windows/macOS 152.0.7977.82/.83、Linux 152.0.7977.82），官方将其描述为 V8 类型混淆漏洞，由 Salvatore Gulizia 于 8 月 4 日报告；NVD 的表述则把定性抬到了沙箱突破层面。

对前端开发者真正值得注意的是长尾：Chromium 不只是 Chrome，Edge、Brave、Opera、Arc、Vivaldi，以及**每一个 Electron / CEF 桌面应用**都自带一份 Chromium 分支，各自需要单独发版。历史上 Electron 跟进上游安全修复的中位滞后是 7-14 天，从 Electron 修好到 Slack、VS Code、Discord、1Password 这类下游应用再发版又是 2-4 周。今年早些时候 Duo Security 的调查显示，41% 的企业部署 Electron 应用跑着落后稳定版 90 天以上的 Chromium。如果你负责的产品带内嵌浏览器、Playwright/Puppeteer 实例或 Electron 打包，现在是查依赖树版本号的时机。社区另外在吵的是赏金——据报道 Google 给报告者约 1000 美元，与灰产市场上六位数的浏览器沙箱利用链形成刺眼对比。

### Bun 1.4.2：紧急修掉 1.4.1 的两个回归（Elysia 构建产物与 AsyncLocalStorage 泄漏）

Bun 在 1.4.1 发布约一天后推出 1.4.2。两个回归都是 1.4.1 引入的：一是 `bun build` 的变量重命名冲突——嵌套作用域里 `var` 被改成与同块 `let` 同名，导致引入 Elysia 的构建产物加载时报 `SyntaxError: Cannot declare a var variable that shadows a let/const/class variable`；同类问题还会让 `let` 取到函数参数或 catch 绑定的名字，代码能跑但结果错。二是 AsyncLocalStorage 内存泄漏：在 `store.exit()` 或嵌套 `store.run()` 中创建的 timer / immediate / pending promise，会让外层 store 的 value 一直存活到该 timer 或 promise 结束，`getStore()` 返回值仍正确，只影响内存。此外还修了 `node:worker_threads` 的 Worker 未先触发 `online` 事件导致 `@discordjs/ws` 挂起、长运行进程中被 GC 的原型引发 JIT 崩溃、musl（Alpine）上对象数组 `splice`/`shift` 的 GC 线程崩溃。新增能力方面，`Bun.Image` 现在能解码 4 通道 CMYK 与 YCCK JPEG（解码时转 RGB），并合入约 350 个上游 WebKit 提交（Intl / TypedArray 正确性、Proxy 崩溃修复、更便宜的 Date 对象）。

### Node.js 当前版本 26.8.1：原生 ZIP 支持与 REPL 语法高亮进入主流视野

Node.js 当前线来到 26.8.1（LTS 线为 24.20.0「Krypton」），本周开始被各大包管理器索引验证为默认推荐版本。26.8.0 带来的原生 ZIP 能力（`ZipEntry` / `ZipFile` / `ZipBuffer`，无需外部依赖即可读写 zip 归档）、REPL 基础语法高亮、统计学假设检验加入性能直方图、TracingChannel 转稳定、SQLite 语句的 `close()` 与 `Symbol.dispose` 支持，是本轮最受关注的几项。26.8.1 是修 `node --version` 误报 alpha 版本号的带外发布。

### 开源工具：wigolo 把 18 个搜索引擎塞进一个 MCP 接口，Stave 查 AWS 配置里的隐藏攻击路径

两个当日出现的开发者工具值得一提。`wigolo` 是本地优先的搜索工具，通过单一 MCP 接口同时查询 18 个搜索引擎，合并结果后用本地模型重排，每条结果附带摘要、来源位置与引用 ID，适合给 Claude Code 接研究流水线。`Stave` 是安全验证工具，不只检查单个 AWS 资源配置，而是分析资源之间的权限与连接关系，找出复合风险路径——比如 S3 加密和公开访问阻断单独看都正常，但它会标出「Bedrock agent → Lambda → 敏感 S3 数据」这类通路。

## 🗓️ 本周其他值得关注的

- **Chrome 153 将于 9 月 8 日进入稳定通道，同时开启两周发布周期**：这是 Chrome 自 2021 年四周期以来的首次节奏调整，桌面/Android/iOS 全部适用；Dev 与 Canary 通道不变，企业用的 Extended Stable 仍保持八周。Chrome 153 还把 Long Animation Frames API 扩展到 dedicated Web Worker（可观测阻塞 Worker 事件循环的长任务），并移除 Related Website Sets、`document.requestStorageAccessFor()` 与 Attribution Reporting API 等一批 Privacy Sandbox API。
- **Firefox 155（9 月 1 日）**：模块加载失败不再被永久缓存为失败——网络错误或 MIME 类型被修正后，再次 import 同一 specifier 可以成功，覆盖 JS / JSON / CSS / text 模块，窗口与 Worker 中的静态与动态加载均适用。
- **Electron 44（8 月 25 日）**：升级到 Chromium 152、V8 15.2、Node.js 24.18.1，新增 `net.WebSocket`、持久化窗口状态、重设计的 Clipboard API，并放弃 32 位构建。当前 44.1.1 / 43.5.1 / 42.11.1 均于 9 月 1 日发布——结合上面的 CVE-2026-85046，Electron 用户应该优先确认自己的版本。
- **Vitest 5.0（9 月 3 日）**：vm 池最高提速 53%、整体约 18%，Browser Mode 内置 Trace View，新增基准测试 API 与 `vi.when`；要求 Node.js 22 + Vite 6.4，含多项破坏性变更。
- **Hono / Fastify 安全补丁（9 月 4 日）**：Hono 4.13.7 修 JSX 渲染 XSS（Suspense / ErrorBoundary / Context.Provider 的纯字符串子节点未转义），Fastify 5.12.3 修 CVE-2026-18504（根级原始 schema 绕过校验）与 CVE-2026-16732（`X-Forwarded-*` 伪造）。
- **Motion v13.2.0（9 月 2 日）**：`framer-motion` 已成为弃用的安装别名，需要从 `motion/react` 导入。
