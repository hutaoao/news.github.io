今天是周一，前端圈跨周末动态颇多，一起来看。

### Kimi K3 正式开源：全球首个 3 万亿参数级开源模型，前端代码能力登顶

月之暗面于 7 月 27 日晚 11 点正式开源 Kimi K3 完整模型权重，这是全球首个落地的 3 万亿参数级开源大模型。K3 在 Frontend Code Arena 前端代码竞技场中以 1679 分登顶，超越 Claude Fable 5。据第三方平台 Artificial Analysis 数据，K3 在保持第一梯队性能的同时，BrowseComp 基准单次任务成本仅为 GPT-5.6 Sol 的一半，较 Claude Fable 5 便宜近一个数量级。开源许可允许个人开发者和企业自由下载部署，对前端开发者的 AI 辅助工作流将产生重要影响。

_来源：[科创板日报](https://so.html5.qq.com/page/real/search_news?docid=70000021_1676a6804a280552) | [CSDN 实测](https://blog.csdn.net/ZhouZYQ_/article/details/163076402)_

### GitHub Issues 大改造：客户端缓存 + 预取让导航速度提升数倍

GitHub 重新设计了 Issues 的导航架构，将更多工作迁移到客户端侧。工程团队引入了客户端缓存、预测性预取以及基于 Service Worker 的请求处理机制，使"即时导航体验"的比例从 4% 一举提升至 22%。该架构使用 IndexedDB 做持久化存储、内存缓存处理会话期间高频访问数据——这套本地优先（local-first）方案对于大型 Web 应用的前端架构设计具有重要参考价值。

_来源：[InfoQ 中文 - GitHub Issues 改造](https://so.html5.qq.com/page/real/search_news?docid=70000021_0336a66efbc18352)_

### Cross-Origin Storage API 提案：按哈希共享跨域大文件

Dennis Morello 提出了一项新的浏览器标准提案——Cross-Origin Storage API，允许浏览器按文件的 SHA-256 哈希值而非 URL 来存储和检索大文件，从而创建跨域共享缓存。开发者通过 requestFileHandle() 方法即可获取文件；若文件已存在则直接返回缓存，否则下载后存储。隐私保护方面，API 设计不暴露文件列表、对不存在的文件返回模糊响应，并支持公开哈希列表供全局共享。

_来源：[Web Standards - Cross-Origin Storage API](https://web-standards.dev/news/2026/07/cross-origin-storage-api/) | [morello.dev](https://morello.dev/blog/cross-origin-storage-api)_

### ECMAScript 2026 正式获批：JavaScript 迎来第 17 版规范

ECMAScript 2026（ES17）正式获批，带来多项实用新特性：Array.fromAsync 支持从异步可迭代对象构建数组、Error.isError() 用于准确识别错误对象、Math.sumPrecise 实现高精度浮点数求和避免精度丢失、Uint8Array 原生 Base64 和 Hex 转换、Iterator.concat() 对多个迭代器顺序连接、JSON.parse 支持源文本访问，以及 Map.getOrInsert() 便捷的 upsert 操作。这些新特性将逐步在各大浏览器和运行时中落地。

_来源：[腾讯新闻 - ECMAScript 2026 获批](https://new.qq.com/rain/a/20260710A002R500) | [Web Standards 解读](https://web-standards.dev/news/2026/07/whats-new-in-ecmascript-2026/)_

### Ternlight：仅 7MB 的 Wasm 嵌入向量模型，浏览器端语义搜索无需后端

Ternlight 将一个 384 维的嵌入模型压缩为 7MB 的 WebAssembly 包，让前端开发者可以零后端、无 API Key 地为任意 JS 应用添加隐私优先的语义搜索能力。这对于构建本地化 RAG 应用、客户端文档搜索、智能问答等场景极具吸引力，也为浏览器端 AI 能力的去中心化部署提供了新思路。

_来源：[NexGismo - Ternlight WASM Embeddings](https://www.nexgismo.com/)_

### TypeScript 7.0 正式发布回顾：Go 重写带来 10 倍性能提升

微软于 7 月中旬正式发布了 TypeScript 7.0（基于 Go 语言完全重写），完整构建速度提升 8-12 倍，VS Code 编译从 125.7 秒降至 10.6 秒。该版本支持 --checkers 和 --builders 并发编译标志、基于 Parcel watcher 重构了文件监听系统、内存占用降低 6-26%，语言服务器崩溃率减少 60%。社区反响强烈，Vue、Astro、Angular 等框架工具链正等待 7.1 稳定 API 适配。  

_来源：[TypeScript 官方博客](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) | [微软公告](https://so.html5.qq.com/page/real/search_news?docid=70000021_1426a59c7e827652)_

### 阿里千问 AI 平台上线：一个 Key 管所有模型

阿里巴巴推出千问 AI 平台，开发者通过一个 API Key 即可访问阿里旗下所有大模型，大幅降低了多模型切换的复杂度。该平台对前端开发者友好，可用于代码生成、调试辅助、文档编写等场景，是国内 AI 编程工具生态的重要补充。

_来源：[暗夜独行博客](https://apisitlee.com/)_

### Chrome 150 / Edge 150 稳定版回顾：system accent colors、text-fit 等新特性

Chrome 150 稳定版于 6 月底发布，带来了系统强调色支持、polygon 圆角、可动画 zoom、url() 修饰符以及 CSS text-fit 属性等新能力。其中 text-fit 用于自动缩放文字大小以适应容器，是期待已久的 CSS 原生功能。Edge 150 同步了这些更新并开放了谷歌账号登录支持。

_来源：[Web Standards - Chrome 150](https://web-standards.dev/news/2026/07/chrome-150/) | [browsers.fyi](https://www.browsers.fyi/)_
