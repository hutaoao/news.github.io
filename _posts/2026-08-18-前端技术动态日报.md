### Oxc 正式支持 React Compiler，22 条 lint 规则上线且性能超 Babel 10 倍

Oxc 项目正式宣布其 JavaScript 工具链全面支持 React Compiler（React 编译器）。**Oxlint** 现已内置 22 条基于 React Compiler 验证通路的 lint 规则，覆盖 useMemo 误用、Effect 中 setState、静态组件等 React 规则，并且这些规则均被纳入 Oxlint 的 `correctness` 分类，启用方式与 ESLint 上游 preset 完全对齐。同时，`oxc-transform-react` 包提供了 React Compiler 自动记忆化（automatic memoization）功能，Oxc 官方透露其基准测试中该包的 Transform 性能比 Babel 快 **10 倍以上**，且即将支持与 `@vitejs/plugin-react` 的集成对接。需要注意的是，原有的 nursery `react/react-compiler` 规则已被替换，使用旧配置的开发者需移除该配置项。此版本为 Oxlinter 带来了重大 breaking change：Oxc 将 React Compiler 的所有规则按类别拆分（split into per-category rules），不再使用单一的 `react/react-compiler` 规则集。

_来源： [React Compiler Support | Oxc Blog](https://oxc.rs/blog/2026-08-18-react-compiler-support)_

### Astro 7.2.3 发布，修复实验性集合存储内存耗尽问题

Astro 在 8 月 18 日发布了 7.2.3 补丁版本，修复了一个在高并发场景下可能导致内存耗尽（OOM）的 bug——该问题仅在启用了 `experimental.collectionStorage` 且设置为 `chunked` 模式时触发。同时，`@astrojs/vercel@11.0.6` 也于同日发布，修复了在 Vercel 部署中 `output: "static"` 模式下服务器岛屿（Server Islands）返回 404 的问题。Astro 7.2 系列近期持续活跃，社区生态与 Vercel 集成度进一步提升。

_来源： [astro@7.2.3 Release](https://github.com/withastro/astro/releases/tag/astro%407.2.3)_

### Solid 2.0 RC 发布：异步正式成为响应式系统第一等公民

Solid.js 团队于 8 月 13 日发布了 Solid 2.0 Release Candidate，核心主题为「异步是一等公民」（Async is first-class）。Solid 2.0 的响应式图（reactive graph）正式将异步计算（可返回 Promise 或异步迭代器）纳入第一层支持，这是一项根本性的架构决策，影响贯穿整个框架的核心设计。相比之前将异步视为需要「应对」的条件，2.0 将异步本身作为响应式系统的属性，模型（Model）承担更多职责，使异步组件的编写体验与同步组件趋于一致。这一 RC 版本的发布标志着 Solid 正式向 2.0 稳定版迈进。

_来源： [Solid 2.0 RC Release](https://github.com/solidjs/solid/releases/tag/v2.0.0-rc.0)_

### Oxc 发布 crates 0.145.0 及 Oxlint 1.79.0：codegen 重构、TypeScript 支持完善

8 月 18 日 Oxc 发布了三连版本：**crates_v0.145.0**、**apps_v1.79.0**（含 Oxlint 1.79.0 和 Oxfmt 0.64.0）。其中 `printSync` API 发生了 **breaking change**（返回类型从字符串改为对象），此外 codegen 模块增加了完整的 Source Map 支持、NAPI/minify 端新增了属性名混淆（property name mangling）选项，以及为 isolated-declarations 模块新增了保留未解析参数类型的修复。Oxlint 1.79.0 集成了最新的 React Compiler 支持（见头条），并大幅增强了 TypeScript 类型感知 lint 能力。

_来源： [Oxc Releases on GitHub](https://github.com/oxc-project/oxc/releases)_

### Angular 连续更新：v22.1.2 修复可选链表达式与 MathML 缺陷

Angular 团队在 8 月 13 日同步推送了三个版本（v22.2.0-next.2、v22.1.2、v21.2.20）。**v22.1.2** 稳定版修复了编译器中可选链（optional chaining）表达式代码生成的错误，以及移除了命名空间 MathML script 元素的生成。**v22.2.0-next.2** 预发布版进一步修复了 `::ng-deep` 嵌套选择器的 CSS 封装问题和主机绑定（host bindings）清理缺陷。值得注意的是 Angular 22.2.0-next.2 还修复了 `::ng-deep` 与嵌套选择器相关的样式隔离问题，这对使用深度选择器进行样式穿透的 Angular 开发者来说是重要修复。

_来源： [Angular Releases on GitHub](https://github.com/angular/angular/releases)_

### Context Engine：为零幻觉 AI Agent 构建无头 IDE

一款名为 **Context Engine** 的开源工具于 8 月 18 日在 HN 上亮相，作者 welf 表示其目的是解决 AI 编程助手的 API 幻觉问题。该工具为 AI Agent 提供了一套类似 IDE 的能力（符号解析、类型推断、代码导航），并以内核（daemon）形式运行，所有支持 MCP 的 AI 工具（Claude Code、Cursor 等）可共享同一个实例，实现跨工具的上下文一致性。它完全本地运行，代码不离开用户机器，支持 JavaScript/TypeScript、Python、Rust、Go 等语言。

_来源： [Context Engine](https://context-engine.app)_

### desktop-fly：macOS 桌面上的果蝇大脑 3D 可视化

开发者 Denis Sergeevitch 于 8 月 18 日开源了 **desktop-fly**，在 GitHub 上一日斩获 264 颗星。这是一个运行在 macOS 桌面上的果蝇大脑连接组（FlyWire connectome）3D 交互式可视化项目，基于真实神经科学数据构建，为前端开发者展示了使用原生桌面框架结合 Web 可视化技术（Three.js/WebGL）实现高质量科学可视化的可能性。
