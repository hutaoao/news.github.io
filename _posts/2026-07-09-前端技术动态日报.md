今日是前端技术生态的大日子——TypeScript 7.0 正式版如期而至，同时还有 Google 的 Web AI 新库、HeroUI 重磅重写等多项热点。

### TypeScript 7.0 正式版发布：14 年来最大变革，性能提升 10 倍

微软于 7 月 9 日正式推出 TypeScript 7.0，这是自 2012 年以来的最重大重构。编译器完整迁移至 Go 语言，借助原生代码速度和共享内存并行处理，编译和类型检查速度相比 6.0 平均提升约 10 倍，内存需求更少。在实测中，打开一个有类型错误的大文件，从编辑器启动到显示首个错误从原来的 17.5 秒降至不到 1.3 秒。TS 7.0 未附带原生 API（计划在 7.1 提供），但微软提供了 @typescript/typescript6 兼容包供旧工具继续使用。npm install -D typescript 即可升级体验。

_来源：[IT之家](https://new.qq.com/rain/a/20260709A02K9600) | [TypeScript 官方博客](https://devblogs.microsoft.com/typescript/)_

### TS 7 社区实测：从「风扇起飞」到「全程静音」

TypeScript 7.0 发布后社区反响热烈。开发者实测显示，纯 tsc 编译从 4.38 秒降至 0.60 秒，完整本地 gate 流程大幅提速。一位开发者表示将项目从 TS6 切换到 TS7 后，机器不再进入风扇明显起转的高压状态，全程静音完成类型检查。社区普遍认为，编译性能瓶颈的消除将直接改变前端大型项目的 CI/CD 流程和开发者日常体验。

_来源：[腾讯新闻 - TS 7 实测](https://new.qq.com/rain/a/20260709A07C4700)_

### Google 发布 LiteRT.js：Web AI 推理速度最高提升 3 倍

7 月 9 日，Google 正式推出 LiteRT.js 库，旨在大幅提升浏览器中 AI 和机器学习工作负载的运行速度。LiteRT.js 采用 WebAssembly 构建，结合 WebGPU 与 WebNN 等硬件加速能力，用于替代 TensorFlow.js 的 JavaScript 内核方案。在搭载 M4 芯片的 MacBook Pro 上实测，相比现有方案速度提升 3 倍。这意味着开发者可以在浏览器端运行更复杂的 AI 模型，而无需牺牲用户体验。Google 官方表示实际性能因硬件和浏览器的不同可能有所差异。

_来源：[IT之家](https://new.qq.com/rain/a/20260710A03GNZ00) | [Google AI Blog](https://ai.googleblog.com/)_

### HeroUI v3 正式发布：为 React 和 React Native 重写，基于 Tailwind CSS v4

HeroUI（前身为 NextUI）发布了 v3 版本，经历了一次从头到尾的彻底重写。新版包含超过 75 个 Web 组件（其中 21 个为新增组件），同时新增一个从零构建的 React Native 库，内含 37 个原生组件。HeroUI v3 基于 React Aria Components 实现无障碍功能，采用 Tailwind CSS v4 进行样式设计，所有动画迁移至 CSS（无需 JS 运行时），完美兼容 React 19 和 Next.js。值得一提的是，这次重写大量采用了 AI 辅助开发，并提供了 MCP 服务器和 Agent Skills 供编码助手直接读取组件文档。

_来源：[InfoQ](https://infoq.cn/) | [腾讯新闻](https://new.qq.com/rain/a/20260709A06KY500) | [GitHub - heroui-inc/heroui](https://github.com/heroui-inc/heroui)_

### ECMAScript 2026 规格正式确认：JS 第 17 版能力全解析

6 月 30 日 ECMA International 批准的 ECMAScript 2026 规格，本周在社区内进一步扩散和讨论。除了此前报道的 Math.sumPrecise、Iterator.concat、Array.fromAsync、Error.isError 等方法外，开发者特别关注 JSON.rawJSON 对序列化输出中原始值精细控制的能力，以及 Map/WeakMap 默认值方法在减少样板代码方面的潜力。W3Schools 也已上线专门的 ECMAScript 2026 学习页面。

_来源：[W3Schools](https://www.w3schools.com/jS/js_2026.asp) | [i-programmer](http://www.i-programmer.info/)_

### Node.js 26 默认启用 Temporal API，JS 日期处理迎来曙光

Node.js 26 版本默认启用了 Temporal API，为 JavaScript 带来了期待已久的现代化日期和时间处理能力。Temporal 解决了 JavaScript Date 对象长期存在的 API 设计缺陷，提供精确的时区感知日期计算、持续时间处理和日历系统支持。对于前端开发者而言，这意味着全栈 JS 应用现在可以在服务端享受与浏览器端一致的、科学的日期时间处理方案。

_来源：[InfoQ](https://www.infoq.com/) | [Node.js 官方博客](https://nodejs.org/en/blog/)_
