八月末前端圈依然热闹：AI 编程工具、Web 平台标准、经典库大版本三线齐发，下面是今日值得关注的动态。

### Claude Code v2.1.251 发布：本周最大安全强化版本

8 月 28 日，Claude Code 连发 v2.1.250 与 v2.1.251 两个版本，后者是本周最重要的安全加固更新。新增 `PreModelSwitch` / `PostModelSwitch` 钩子（可拦截、确认或记录模型切换）、前台子代理的工具调用实时流式推送到 Remote Control 客户端、`/usage` 的 Spend limit 进度条，以及 `/cost` 的按会话 prompt-cache 明细。同时一次性修复了 5 个安全问题：符号链接文件工具越权、插件市场路径穿越、Workflow 脚本路径越权、Grep/Glob 符号链接拒绝规则绕过等。

_来源：[Claude Code 官方更新日志](https://code.claude.com/docs/en/changelog)_

### htmx 4.0.0 发布：用 fetch 重写传输层、内置 morph 交换

8 月 28 日，htmx 4.0.0 正式发布。最大的变化是用浏览器 `fetch()`（配合 `ReadableStream`）替换了沿用多年的 `XMLHttpRequest`，从而原生支持 HTML 流式渲染；Idiomorph 合并算法进入核心，新增 `morphInner` / `morphOuter` 交换模式；并带来 `hx-sse` / `hx-ws` / `hx-multipart` 流式扩展与受 Alpine/hyperscript 启发的 `hx-live` 脚本层。破坏性变更主要是属性继承改为显式（需加 `:inherited` 后缀），团队刻意将其保留在 npm 的 `next` 标签直到 2027 年初，2.x 仍是 `latest`，避免 CDN 用户被强制升级。

_来源：[htmx 官网](http://htmx.org/) · [byteiota 升级指南](https://byteiota.com/htmx-4-0-fetch-api-morphing-upgrade-guide)_

### Chrome 153 稳定版陆续推送，8 月 Web 平台多项进入 Baseline

Chrome 153 已于 8 月 26 日向 Windows / Mac 推送早期稳定版，8 月 27 日 Android 稳定版开始滚动。本轮新增能力包括：Capability 元素（`<video-capture>` / `<audio-capture>` 单一能力采集）、IAMF 空间音频解码、TC39 的 `Iterator.join()` 与 Joint Iteration、单轴滚动容器（`overflow: scroll clip`）、WebAudio 可配置 render quantum、WebGPU `buffer_view` 特性，以及非 XSLT 场景的 XML 解析改用内存安全的 Rust 实现。web.dev 的八月盘点还显示：`text-box` 系列属性、`sibling-count()` / `sibling-index()`、`autocorrect` 全局属性均在本月达成 Baseline（Newly available）。

_来源：[Chrome Releases](https://releases.sh/google/product/chrome) · [web.dev：New to the web platform in August](https://ilo.im/16fp3s)_

### SvelteKit 3 进入 Release Candidate

SvelteKit 3 已发布首个 RC，官方表示稳定版前不会再引入破坏性变更。这一大版本将配置从 `svelte.config.js` 迁入 `vite.config.ts`、`$lib` 别名改为 `#lib`、新增 `$app/manifest` 与 `$app/service-worker` 模块、`refreshAll` 取代 `invalidateAll`、`goto` 内建浅层路由、支持 `QUERY` HTTP 方法，并能自动检测新部署。迁移可通过 `npx sv@next migrate sveltekit-3` 完成，未迁移的项目仍可稳定使用 SvelteKit 2。

_来源：[Svelte 官方博客：What's new in Svelte: August 2026](https://svelte.dev/blog/whats-new-in-svelte-august-2026) · [SvelteKit 3 RC](https://releasebot.io/updates/sveltejs)_

### Cursor Cloud Agents 重大更新：免 GitHub 起步、浏览器实时预览、一键发布 Vercel

Cursor 8 月 27 日更新让 Cloud Agents 不再强制要求连接 GitHub 等第三方 SCM：在仓库选择器里选「Start from scratch」，直接对 agent 下指令，需要时再一键保存为 Cursor Origin 仓库。同时把云端 agent 的运行环境通过端口转发直接预览到浏览器，可配合 design mode 使用；连接 Vercel 账号后即可发布为线上 URL。更早的 8 月 19 日更新还带来了事件订阅（监控 PR / Slack 线程 / 定时任务）、持久化 `/goal`、以及运行在独立虚拟机上的子代理。

_来源：[Cursor Changelog](https://cursor.com/changelog)_

### Deno 2.9.6 发布

Deno 于 8 月 27 日推送 2.9.6，延续 2.9 系列的小步迭代。2.9 线此前已带来 `deno desktop` 桌面应用子命令、Blob/Body `textStream()`、实验性 QuickJS 后端、React Router 自动识别与 HMR 等能力，冷启动约 2 倍提速、RSS 内存最高 3 倍下降。

_来源：[Deno Releases](https://releases.sh/deno)_

### This Week in React #294：React Compiler 全面推进、React 19.3 将至

本期周报（8 月 19 日刊）聚焦 React 生态多条主线：React Compiler 的 Rust 移植持续推进，Oxlint 1.79 已加入支持、`oxc-transform-react` 包可解锁自动 memoization，Biome 2.5.8 带来 `useReactCompiler` 实验规则，Bun 1.4 也通过 `--react-compiler` 内置支持；React 19.3 临近，Fragment refs 与 `ViewTransition` 将在该版本稳定；TanStack Router 被以最高 19 倍提速的方式重新实现；Cursor 则从 Solid v1 迁移到 React + StyleX（社区解读为 signal 方案存在性能陷阱）；React Native 0.87 已发布，为 v1.0 铺路。

_来源：[This Week in React #294](https://dev.to/sebastienlorber/this-week-in-react-294-react-compiler-tanstack-nextjs-gtkx-effect-rn-087-screens-rngh-4p6c)_
