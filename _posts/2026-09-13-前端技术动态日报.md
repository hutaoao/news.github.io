周末的两条硬新闻都在「包管理与技能生态」上：Homebrew 7.0.0 发布了第一个原生 macOS 图形应用和内置漏洞数据库，GitHub 周榜则被 Agent Skills 类项目彻底占据——榜单前十的累计 Star 全部超过 25 万，且无一例外都在讲同一件事：怎么给智能体造标准化能力。

### Homebrew 7.0.0 发布：原生 macOS 应用 BrewUI、内置漏洞库、Intel Mac 降到 Tier 3

Homebrew 7.0.0 于 9 月 13 日发布，是 6.0.0 之后最大的一次更新，官方列出的重点包括更快的安装升级、更强的沙箱、原生 macOS 应用、**内置漏洞检查与公告数据库**、停止支持 macOS 10.15、以及把 Intel Mac 降到 Tier 3。性能上，`brew install`/`reinstall`/`upgrade` 现在会**重叠执行包的准备与下载**以减少包之间的等待，`brew config`、`brew tap-info` 等命令并发收集系统信息，`brew cleanup` 不再重复扫描缓存。安全上是这次最实的一块：公式与 cask 操作都进沙箱，默认阻止沙箱读取用户主目录；新增 **`brew vulns`** 命令与 [Homebrew advisory database](https://github.com/Homebrew/advisory-database)，基于 OSV.dev 检查已知漏洞，不再需要额外 tap 或 gem。开发者体验上，官方图形界面 **BrewUI** 正式发布（`brew install homebrew-app`，需 macOS Tahoe 26+），提供包浏览、搜索与命令可视化；Linux 侧用 **Landlock** 替换了 6.0.0 引入的 Bubblewrap，不再需要额外依赖或提权的 Docker 权限。需要提前规划的两件事：**Intel Mac 将不再有新 bottles**（项目运行到 2027-09-01），以及 formula 的 `post_install` 与 cask 的 `*flight` Ruby 块被弃用（计划 2027-12-11 移除），建议改用声明式的 `*_steps`，`brew style --fix` 可以帮忙迁移。

_来源：[Homebrew 7.0.0 官方公告](https://brew.sh/2026/09/13/homebrew-7.0.0/)_

### GitHub 周榜被 Agent Skills 彻底占据，「上帝之眼」登顶飙星榜

截至 9 月 13 日的 GitHub 周榜呈现出非常清晰的单一主导方向：**前 20 名里过半是面向 Agent 的「技能」类项目**，累计 Star 最高的三个（obra/superpowers 285,823、mattpocock/skills 260,506、affaan-m/ECC 257,136）全部属于 Skills 或 Agent 方法论范畴。周增榜前五是 **ayghri/i-have-adhd**（+15,924，让编码 Agent 先给答案、少说废话的 Skill）、**bilawalsidhu/gods-eye-view**（+10,510，浏览器里的实时地球）、**tt-a1i/archify**（+10,442，把代码库编译成可验证架构图）、**DietrichGebert/ponytail**（+9,272，让 Agent 像「最懒的资深工程师」一样只写必要代码，实测减约 54% 代码量、省约 20% 成本、提速约 27%）、**mattpocock/skills**（+8,960）。非 Skills 类项目只有 gods-eye-view、hyperframes、markitdown、WeKnora、OpenMAIC 等少数几个，且大多在描述里写着「Built for agents」。**日榜**方面，9 月 13 日 gods-eye-view 从第 2 升到第 1（30,623 星），`asgeirtj/system_prompts_leaks` 以 65,633 星新进第 3，`melgarafael/DeskcommCRM` 升到第 2，而前一天的榜首 i-have-adhd 与 obra/superpowers 双双跌出前十。社区总结的两句话值得记住：从「用 Agent」走向「为 Agent 造标准化能力」，以及从「能生成」转向「可信、可控、更省」。

### Claude Code 12 天 12 个版本：Fable 5.1 成默认、/diff 面板、插件评测

把 9 月 1 日到 12 日的 Claude Code 拉成一条线看，它跑完了 **12 个编号版本（2.1.257 → 2.1.270），接近一天一版**。2.1.257 把 `claude-fable-5-1` 设为默认 Fable 模型（1M 上下文，$10/$50 每百万 token，缓存读取 $0.25/Mtok），并在 auto 模式加入阻止云元数据凭证抓取的 Containment Escape 规则；2.1.260 加入全屏模式下的常驻 diff 面板（`/diff` 切换，实时显示未提交改动）；2.1.261 带来 `/skill-doctor`，显示哪些已加载技能从未被使用及其上下文成本；2.1.265 支持把 `--plugin-dir` 指向一个插件文件夹、并把落盘的工具结果上限压到 1 GB；2.1.267 的 `maxEffortLevel` 可跨所有已配置 provider 限制推理投入；2.1.269 是我们昨天详细写过的那一版。两次自我修复也很能说明节奏：2.1.266 用了不到一天修掉 2.1.265 里 `CLAUDE_CODE_USE_GATEWAY` 强行触发 Cloud 网关登录、导致 API-key 与自定义认证配置失效的问题；2.1.268 修掉自 2.1.265 起第三方 Anthropic 兼容端点（`ANTHROPIC_BASE_URL`）每一轮都返回 HTTP 400 的回归，并给 WebFetch 加上 300 秒超时。服务状态上有一条需要提醒：**Claude Cowork on Windows 无法执行本地命令**的故障自 9 月 10 日开启，到 9 月 13 日已进入第四天（Windows 在 9 月 8 日的更新后 Cowork 工作区无法访问用户磁盘），聊天与文件读写正常，受影响团队可临时切到 Claude Code CLI。

### 三大编码代理同期综述：Codex 上 worktree、Copilot 上 HydraFusion、OpenCode 追模型

用同一时间窗横向看三家主流编码代理，走向差异相当明显。**Codex CLI** 0.154.0（9 月 9 日）是功能动作最多的：GPT-6-Astra 进模型选择器与 Bedrock、实验性 worktree、任务中内联问答、Windows 共享后台 server，代价是移除了 `codex mcp-server` 这个破坏性变更。**GitHub Copilot** 的 9 月 7 日周报把 Jira 拉进 Copilot 应用、把 HydraFusion 放进 CLI `/experimental`、给 VS Code 1.137 加上智能体定时任务与语音模式；代码审查侧则在 9 月 11 日把 Lite 档换成多智能体 ensemble。**OpenCode** 在同一个窗口发了 v1.18.26 到 v1.18.30，主要工作是补齐 GPT-6-Astra 的可见性与 provider 兼容（Bedrock、Azure、GitHub Copilot 认证），属于「跟随上游厂商节奏」的典型。三家的共同点也很清楚——权限与沙箱修复是这周的绝对主线：Claude Code 修两处 deny 规则绕过、Codex 收紧启动时的 workspace trust 并让 macOS 沙箱阻止终端输入注入、Gemini CLI 0.59.0 修 MCP OAuth 的 SSRF 并强制 fail-closed 的工作区信任。**如果你的脚本或 CI 里锁了模型名，务必检查 10 月 2 日的弃用清单**（Gemini 3.5/3.6 Flash、Kimi K2.7 Code、Claude Opus 4.7）。

### Stripe 75 亿美元收购 OpenRouter：模型路由层的「中立性」开始被追问

Stripe 收购 OpenRouter 的交易细节在本周持续发酵。8 月 19 日 Stripe 确认收购、未披露金额，《纽约时报》报道约 **75 亿美元**（约 15 亿给创始人、60 亿给投资人），而 OpenRouter 在 5 月的 B 轮估值是 13 亿美元——**三个月翻了约 5.8 倍**。这家 2023 年成立、仅 82 名全职员工的公司自己一个模型都没训练过，只做一件事：决定每次请求交给哪个 AI 模型，聚合 80 多家供应商的 400 多个模型。同一天 Ramp 上线了竞品 Router，2026 年底前免费——这件事的意义不在价格，而在它说明**路由层「值得花几十亿买下、同时不值得向用户收费」**，因为网关是唯一能看到你全部模型账单的组件。对使用者的实际提示是三条：检查你自己的路由配置允许自动回退到什么（此前 OpenRouter 最热门的免费条目 `ox-alpha` 事后被确认是 Z.ai 的 GLM-5.3-Flash，且提示词由未披露的提供商保留）；确认关键自动化有回退到厂商直连 API 的文档化路径；把「网关归谁所有」纳入供应商集中度风险清单。同期另一家在国内鲜少被讨论的动作是 **Salesforce 把编码智能体搬进 Slack（Slack Code）**，让产品与设计也能直接在 Slack 里与编码代理交互并看实时预览——把 AI 编程从单人窗口推成多人协作空间。

### 中文侧周报：Rust 工具链全面接管与「AI 前端岗位薪资冲上 70K」

掘金上的《前端生态周报第二期》给出了本轮一个有说服力的宏观判断：**「Rust 构建工具爆发」已经不是趋势而是现状**——Vite 8 默认引擎是 Rolldown（Rust）、Next.js 16 的 Turbopack 是 Rust、Tailwind v4 的 Oxide 引擎是 Rust、pnpm 12 是 Rust、Bun 2.x 是 Rust、Oxc 工具链全套是 Rust，从 parser 到 linter 到 bundler 到 formatter 到包管理器到运行时，整条工具链被重写了一遍。真实项目反馈：Linear 生产构建从 46 秒降到 6 秒，Ramp 构建时间下降 57%，Beehiiv 优化幅度 64%；pnpm 12 用 Rust 重写后热安装从 472 ms 压到 15 ms，空闲 CPU 使用率降低 5 倍，内存最多减少 35%。周报的另一条观察是 AI 编程工具的动向明确收敛到「Cloud Agent + 可视化编辑 + 统一智能体」三个方向（Cursor Cloud Agents 扩展到 AWS Lambda、Cloudflare、Coder、Daytona、Modal 等已有云平台，Bolt.new 上线可视化 Visual Edits，Trae 把 Solo Agent 与 Agent 合并为统一 Agent），并提到 AI 前端岗位薪资冲上 70K。周报也点出前沿框架的共同取向：React 19.3 的 View Transition、Vue 3.6 的 Vapor、Solid 2.0 都在往「无虚拟 DOM + 编译时优化」走，Svelte/Angular/Nuxt 本周无新 RFC 或 breaking change。
