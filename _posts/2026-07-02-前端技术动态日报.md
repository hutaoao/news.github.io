前端生态本周迎来多个重要里程碑，新运行时版本、语言规范定稿和 AI 编程工具都在持续进化。

### Deno 2.9 发布：新增 `deno desktop` 原生桌面构建能力

Deno Land 于 6 月 25 日正式发布 Deno 2.9，核心亮点是全新的 `deno desktop` 功能——开发者可直接使用 Web 技术栈（HTML/CSS/JS）构建原生桌面应用，无需 Electron 的繁重脚手架，最终输出单一二进制文件。同时该版本在启动时间、内存占用和 HTTP 吞吐量方面均有显著优化。这一能力的加入让 Deno 在桌面端与 Tauri、Electron 形成了直接竞争关系。

_来源：[InfoQ - Deno 2.9 Adds Desktop App Builder](https://www.i-programmer.info/news/167-javascript/18147-deno-29-adds-desktop-app-builder.html) | [腾讯网](https://new.qq.com/rain/a/20260702A08GLP00)_

### ES2026（ECMAScript 2026）正式定稿

ECMAScript 2026 规范正式落地，带来多项值得关注的语言特性：资源管理 `using` 和 `await using` 声明（借鉴 C# 模式，自动释放资源）、`Error.isError()` 错误检测方法、`Array.fromAsync()` 从异步可迭代对象创建数组、`Uint8Array` 新增 Base64 和 Hex 编解码静态方法，以及 Temporal API 的正式标准化——作为现代日期时间管理替代遗留的 `Date` 对象。此外，元组（Tuples）和模式匹配（Pattern Matching）已进入 Stage 3。对前端开发者来说，Temporal API 的普及将大幅简化日期操作。

_来源：[W3Schools - JavaScript 2026](https://www.w3schools.com/jS/js_2026.asp)_

### Cursor 移动端 App 持续升温，开发者热议「手机编程」场景

6 月 30 日 Cursor 正式发布 iOS 版移动端应用后，本周开发者社区持续热议。该应用支持语音输入和斜杠命令启动 Agent、远程控制桌面端已运行的 Agent、查看代码差异并合并 PR。虽然并非「在手机上写代码」，而是「用手机管理编程 Agent」，但这一方向标志着 AI 编程工具正从桌面走向移动化——开发者的工作空间已不再局限于办公桌前。

_来源：[Cursor 官网](https://www.cursor.com/) | [智东西](https://so.html5.qq.com/page/real/search_news?docid=70000021_9556a439bfb60552)_

### Claude Sonnet 5 全面开放，成为 Claude 新默认模型

Anthropic 于 6 月 30 日发布的 Claude Sonnet 5 本周已成为所有 Claude 用户的默认模型。它号称「最 Agent 化的 Sonnet」，在 SWE-bench Pro 上达到 63.2%，接近旗舰 Opus 4.8 水平，而价格仅为其 40%-60%。对前端开发者而言，这意味着可以用更低成本完成代码生成、重构和调试任务。社区讨论焦点在于：Sonnet 5 在性价比上是否真能取代 Opus，以及它的工具调用能力是否已足够替代日常开发中的 AI 编程助手。

_来源：[Anthropic 官方](https://www.anthropic.com/) | [CSDN](https://blog.csdn.net/qq_36729037/article/details/162524362)_

### OpenAI Codex 用户量半年增长 5 倍，周活突破 500 万

OpenAI Codex 项目负责人 Andrew Ambrosino 透露，Codex 今年上半年周活跃用户增长超过 5 倍，目前已超过 500 万周活用户。在 OpenAI 内部，近 90% 员工（包括法务、财务、市场团队）每周使用 Codex。这一数据反映了 AI 编程工具正从「开发者专属」走向「全公司通用」的趋势。Codex 的 Windows 桌面端已于今年 3 月发布，支持多 Agent 并行工作。

_来源：[腾讯网 - Codex 取代 ChatGPT](https://so.html5.qq.com/page/real/search_news?docid=70000021_0796a430abe08952) | [CSDN - Codex 安装部署](https://blog.csdn.net/weixin_44822948/article/details/161214604)_

### 框架与运行时生态：Bun vs Node.js 实战讨论升温

随着 Bun 在社区中的应用越来越多，本周多篇技术文章聚焦于 Bun 与 Node.js 的实战对比，涵盖 HTTP 服务器性能、迁移成本和生态兼容性。从前端工程化的角度看，Bun 的启动速度和内置工具链（打包器、转译器、测试运行器）使其在 CI 场景和全栈项目中展现出独特优势，但 Node.js 的生态成熟度仍是关键考量。
