7 月伊始，前端生态迎来多项重要更新。

### Safari 技术预览版 247 引入 MCP 服务

苹果 WebKit 博客昨日（7 月 1 日）发布博文，宣布在 Safari 技术预览版 247 中引入 MCP 服务器支持，用于加速网页开发和调试流程。Safari MCP 服务器通过连接到 Safari 浏览器窗口，让智能体充分了解代码在浏览器中的实际呈现。这是大型浏览器厂商首次原生集成 MCP 协议，标志着 AI Agent 辅助的前端开发进入新阶段。

_来源：[IT之家 | WebKit 博客](https://new.qq.com/rain/a/20260702A01ZIQ00)_

### 2025 JavaScript 状态调查最终版发布

2025 年 JavaScript 现状调查报告（2 月发布）数据持续引发讨论。调查显示 40% 的受访者如今完全使用 TypeScript 开发（2024 年为 34%，2022 年为 28%），而仅使用纯 JavaScript 的受访者仅占 6%，TypeScript 的主导地位进一步巩固。

_来源：[State of JS 2025](https://stateofjs.com/)_

### Deno 2.9 正式版上线，跨平台桌面应用成亮点

Deno 2.9 稳定版正式发布，官网已更新至该版本。核心亮点是支持使用 Web 技术创建跨平台桌面应用，无需 Electron 或 Tauri 即可构建原生桌面程序。同时零配置、标准库 Web API 兼容性等特性持续完善。

_来源：[Deno 官网及发布说明](https://deno.com/)_

### 2026 年 GitHub 热门项目加速向 Agent 工具集中

掘金等平台发布的 2026 年 5 月 GitHub 十大热门项目排行显示，社区火力集中在「把 Agent 做进工程化工作流」这一方向。从 skills 到 MCP 服务器，开源项目围绕 Token 节省、上下文记忆、多 Agent 编排等方向密集创新。

_来源：[稀土掘金](https://juejin.cn/)_

### Recharts 3.9 与 Mantine v9.4 发布

React 生态的两大组件库同步更新。Recharts 3.9 添加了新的动画效果和使用指南；Mantine v9.4 作为功能丰富的组件套件持续升级。RC 组件库生态的持续活跃表明 React 在 UI 组件领域的主导地位依然稳固。

_来源：[Recharts 发布说明](https://recharts.org/) | [Mantine 发布说明](https://mantine.dev/)_

### 2026 年 7 月技术事件日历：AI 编程工具竞争白热化

多家媒体汇总的 7 月技术事件日历显示，本月 AI 编程工具市场竞争将进入白热化阶段。DeepSeek V4 正式版预计中旬上线、Cursor iOS 公测刚刚开始、Claude Code 持续推进功能更新。前端开发者面临「用什么 AI 工具」的选型难题。

_来源：[腾讯新闻 - 7月技术事件日历](https://so.html5.qq.com/page/real/search_news?docid=70000021_3306a4325a316552)_
