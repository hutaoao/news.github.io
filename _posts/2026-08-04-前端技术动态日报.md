周二好！昨天（8 月 3 日）微软正式发布 TypeScript 7.0，前端工具链迎来 Go 原生编译器时代；Remix 3 Beta 的「去 React 化」重写更是引爆社区讨论，两条重磅消息让这天格外热闹。

### TypeScript 7.0 正式发布：Go 原生编译器带来 8-12 倍提速

微软正式发布了 TypeScript 7.0，这是首个搭载长期研发的原生编译器（Go 移植版）的稳定版本。据官方称，完整构建速度通常提升 8 到 12 倍；此前作为 @typescript/native-preview 包已积累超 850 万周下载量，如今 nightly 构建回归标准 typescript 包。7.0 意味着 TypeScript 编译器正式从 TS 自举走向 Go 原生实现，与 Vite、Oxc 等 Rust/Go 工具链的「非 JS 原生化」浪潮合流，对大型 monorepo 的构建体验将是质变。

_来源：[InfoQ](https://www.infoq.com/news/2026/08/typescript-7-released/)_

### Remix 3 Beta 预览版发布：彻底重写，放弃 React 运行时

Remix 联合创始人 Michael Jackson 宣布了 Remix 3 的 Beta 预览版（v3.0.0-beta.5），这是一次从底层开始的完全重构：框架从「中心栈」定位升级为覆盖路由、中间件、认证、表单、上传、数据管理等能力的完整全栈体系，并以小型可组合包组织。最颠覆的变化是前端保留了 JSX 却移除了 React 运行时，改用基于 Preact 分支的命令式模型，路由全面基于 Fetch API，服务器驱动 UI 通过带 src 属性的「frames」片段实现，被观察者认为类似 HTMX 的哲学。团队表示将每周持续发布新版本。

_来源：[腾讯新闻（InfoQ 中文）](https://new.qq.com/rain/a/20260804A09U0400)_

### Chrome 首次官方登陆 ARM64 Linux：填补 6 年空白

谷歌在官方下载页面悄然上架了 Chrome 浏览器的原生 ARM64 Linux 版本，提供适用于 Debian/Ubuntu 的 DEB 包和 Fedora/openSUSE 的 RPM 包。这是 Chrome 首次为通用 ARM64 Linux 发行版提供官方原生支持，填补了长达 6 年的空白。该版本此前承诺于 2026 年第二季度推出，虽略有延期但最终在 8 月初落地——对使用 ARM 服务器的开发者和树莓派等 ARM 设备用户来说，前端开发与测试体验将明显改善。

_来源：[腾讯新闻](https://new.qq.com/rain/a/20260804A0DBJ200)_

### Taro 3.6.6 发布：新增 interceptorify、getAppInfo API

跨端框架 Taro 发布 3.6.6 版本。新特性包括 Taro.interceptorify API、Taro.getAppInfo API，支付宝小程序支持自定义 Tabbar（#13610），并新增 getRenderer 方法获取页面渲染引擎类型及注入 CSS 属性支持的运行时钩子。修复方面涵盖微信小程序视频号 API 的 Promise 化、logInterceptor 生产环境无日志输出、history.state 不符合 Web 规范等问题，H5 端修复了 Swiper 衔接模式与 Textarea confirm 事件等。跨端小程序开发稳定性进一步夯实。

_来源：[GitHub Release](https://github.com/NervJS/taro/releases/tag/v3.6.6)_

### 鸿蒙生态大会 2026 定档 8 月底：规模为历届之最

8 月 3 日，鸿蒙生态大会 2026（HEC·2026）新闻发布会在深圳举行，宣布大会将于 8 月 29 日至 30 日在深圳会展中心（福田）举办。本届大会以「新智联·新未来」为主题，由全球智慧物联网联盟（GIIC）主办，将设置近 3000 平方米沉浸式实景展馆，预计参会规模达 6000 至 8000 人，为历届之最。对前端开发者而言，鸿蒙生态的持续扩张意味着 ArkTS/ArkUI 开发岗位与跨端适配需求将继续增长。

_来源：[腾讯新闻](https://so.html5.qq.com/page/real/search_news?docid=70000021_2486a70992b60352)_

### 阿里 Qwen3.8 正式发布：编程与办公能力大幅提升

8 月 3 日，阿里巴巴正式发布新一代基座大模型 Qwen3.8，总参数量 2.4 万亿，在编程（Coding）和专业办公（Cowork）方面能力大幅提升。API 已上线千问 AI 平台，国内每百万 Tokens 输入 12 元、输出 36 元，输入输出国际价格分别仅为 Opus5 的 40% 与 24%。Qwen3.8-Max 预计下周开源，同时开源 Qwen3.8-27B。作为前端开发者日常使用的 AI 编码底座之一，其编程能力跃升值得关注。

_来源：[腾讯新闻](https://so.html5.qq.com/page/real/search_news?docid=70000021_2676a713cb754252)_

### Firefox 153.0.3 发布：修复 Windows 快捷方式被标记不受信任

Mozilla 于 8 月 4 日发布 Firefox 153.0.3 版本更新，重点改进 Windows 10/11 系统上浏览器快捷方式被标记为不受信任的问题。此前大量用户反馈升级后桌面与任务栏快捷方式被 SmartScreen 标记，导致无法正常启动，此版本予以修复。同时近期 Firefox Nightly 频道已开启 Project Nova 界面改版体验，浏览器 UI 现代化进程持续推进。

_来源：[腾讯新闻（IT之家）](https://so.html5.qq.com/page/real/search_news?docid=70000021_1676a729c4b81452)_
