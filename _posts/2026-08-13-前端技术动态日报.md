8月13日，前端与 AI 编程工具领域迎来多项重要更新，DeepSeek V4 Pro 正式版上线并宣布 API 调价，Claude Code 自动模式明日正式默认启用，IDE 侧 JetBrains 双双推送重要版本。以下是详细动态。

### DeepSeek V4 Pro 正式版发布：100 万 Token 上下文、API 定价 8 月 17 日大幅调整

DeepSeek 于 8 月 13 日正式发布 V4 Pro 正式版，已同步上线 APP、网页端和 API。核心规格方面，上下文长度达到 **100 万 Token**，最大输出长度 38.4 万 Token，模型默认开启思考模式，同时支持切换为非思考模式。API 接口同时提供 OpenAI 格式与 Anthropic 格式，全面支持 JSON Output、Tool Calls、Responses API，可直接导入 Codex 使用。相比 4 月预览版，V4 Pro 正式版在 Agent 能力上实现大幅跃升，多项 Agent 基准测试成绩显著提升。

与此同时，DeepSeek 宣布对 API 价格进行大幅调整，新价格将于 **北京时间 8 月 17 日零时生效**，同时引入峰谷定价机制，部分模型价格涨幅超过三倍。API 用户需注意成本变化，建议在调价前完成必要调用规划。

_来源：[企鹅号 - DeepSeek-V4-Pro 正式版上线](https://so.html5.qq.com/page/real/search_news?docid=70000021_5346a7dcb0481352)_

### Anthropic Claude Code 自动模式明日（8 月 14 日）起默认启用

Anthropic 宣布，从 8 月 14 日起，Claude Code 的**自动模式（Auto Mode）** 将作为默认设置面向 Pro、Max 和 Team 账户开放。这意味着 AI 编程助手将大幅减少向开发者请求手动审批的频率，仅在可能造成不可逆损害时才会暂停操作。公司同步公布了一项覆盖 1053 名付费测试者的研究数据，显示自动模式在捕捉有害操作方面比人工审查更安全。Claude Code 还支持了 AI 会话间跨窗口通信能力，不同会话的 AI 现在可以相互发送消息交换进度，进一步向多 Agent 协作方向演进。

_来源：[企鹅号 - Claude Code 自动模式默认启用](https://so.html5.qq.com/page/real/search_news?docid=70000021_9556a79850002152)、[企鹅号 - Claude Code AI 跨会话通信](https://so.html5.qq.com/page/real/search_news?docid=70000021_5176a76fb0791452)_

### WebStorm 2026.2 正式发布：TypeScript 7 开箱即用，原生 GitHub Copilot 与 Agent Skills

JetBrains 于 7 月 23 日发布 WebStorm 2026.2 正式版，该版本**附带开箱即用的 TypeScript 7 支持**，提供更快的类型检查，无需进行项目迁移即可使用 TS7 新特性。编辑器方面带来了投票最高的多个修复，Git 工具和设置体验均有改进。作为前端开发者最主流的 IDE 之一，WebStorm 2026.2 还引入了原生 GitHub Copilot 深度集成和 Agent Skills 工作流支持，进一步将 AI 能力融入日常编码体验。

_来源：[脚本之家 - WebStorm 2026.2](https://www.jb51.net/softs/598714.html)、[慧都网 - WebStorm 2026.2 正式发布](https://www.evget.com/news)_

### IntelliJ IDEA 2026.2.1 推送：前端开发相关改进一览

JetBrains 于 8 月 11 日推送 IntelliJ IDEA 2026.2.1 更新，作为 2026.2 系列的补丁版本，集中呈现了 AI 辅助能力、Git 与 Docker 工作流等方向的改进。该版本对前端开发者也有间接价值：Gradle 依赖管理体验优化有助于管理包含前端资源的前后端一体项目；Git 工具链改进对处理 monorepo 中的前端子模块尤为实用。

_来源：[慧都网 - IntelliJ IDEA 2026.2.1 更新](https://www.evget.com/news)_

### IDE AI 编程工具横评持续：Claude Code vs Cursor vs GLM vs Kimi

2026 年 AI 编程工具订阅市场持续火热，多个平台推出了横向对比指南，帮助开发者根据价格、额度与 IDE 支持情况选择最适合的方案。Claude Code（200K tokens 上下文，对复杂代码库理解能力最强）、Cursor（AI-first IDE 体验流畅）、GLM Coding Plan、Kimi Code、阿里云百炼等产品形成差异化竞争格局。前端开发者反馈显示，Claude Code 在复杂算法和架构设计场景优势明显，Cursor 在 IDE 原生集成方面体验更佳，Copilot 覆盖面广但深度相对有限。

_来源：[CodingPlan.run - AI Coding Plan 2026](https://codingplan.run/)、[SegmentFault - AI 编程工具对比](https://segmentfault.com/a/1190000047759440)_
