昨日（7月6日）前端圈最受关注的事件集中在 AI 编程工具与大模型赛道，大厂动作频频，开源生态持续活跃。

### 腾讯混元 Hy3 正式发布，元宝接入 Agent 能力

7月6日，腾讯混元 Hy3 正式版发布，采用 MoE 架构，总参数 295B、激活参数 21B，支持 256K 上下文。相比 preview 版本，Hy3 展现出强于同尺寸模型且比肩参数规模 2—5 倍旗舰模型的智能水平，定价进一步降低。基于 Hy3 在 Agent 能力上的大幅提升，元宝同步上线 Agent 功能——用户聊天即可直接生成 PPT、Word、Excel、PDF、HTML 等文件。目前 Hy3 已在 WorkBuddy、CodeBuddy、元宝、Marvis、ima 等多个业务接入，API 同步上线腾讯云 TokenHub。

_来源：[腾讯混元Hy3正式发布（腾讯新闻）](https://news.qq.com/rain/a/20260706A07M5600)_

### 阿里巴巴 Page Agent 开源：纯 JavaScript 自然语言操控网页

阿里巴巴开源了 Page Agent（GitHub: alibaba/page-agent），一个纯 JavaScript 实现的页面内 GUI Agent。它无需 Python 运行环境、无需浏览器扩展、无需截图，直接在浏览器中以脚本方式运行，通过自然语言指令操控网页。项目采用 TypeScript 编写，MIT 协议，目前已迭代至 v1.11.0，提交超过 1000 次，曾登上 Hacker News 首页。对前端开发者而言，这意味着可以用最熟悉的 JS 堆栈直接构建 AI 驱动的网页自动化能力。

_来源：[Page Agent GitHub 仓库](https://github.com/alibaba/page-agent)_

### Google Gemini 3.5 Pro 传闻 7 月 17 日发布，前端代码能力对标 Fable 5

7月6日市场消息称，谷歌新一代大语言模型 Gemini 3.5 Pro 将于 7 月 17 日正式发布。据传其前端与视觉代码生成能力实现跨越式跃升，在多项测试中对标 Anthropic 的 Claude Fable 5。该模型原定 6 月发布，后因 Google DeepMind 放弃原有 2.5 Pro 基座、转为全新预训练而延期。此次发布被视为谷歌应对 OpenAI GPT-5.6 与 Anthropic Fable 5 竞争压力的关键动作。

_来源：[谷歌Gemini 3.5 Pro传7月17日发布（观点网）](https://new.qq.com/rain/a/20260706A07MYC00)_

### GitHub 的旧模式被「AI 击穿」——Cursor、GitLab、Zed 各自开打

TheNewStack 发布深度分析文章，探讨 GitHub 的传统模式正被 AI 编程工具冲击。6月16日，Elon Musk 的 SpaceX 同意以 600 亿美元估值收购 Cursor 的选择权，同日 Cursor 在旧金山闭门会议上宣布了对开发者工具行业具有重大影响的新项目。与此同时，GitLab 和 Zed 也在加速布局 AI 原生开发体验。传统代码托管平台面临着从「代码仓库」向「AI 驱动开发平台」的范式转变压力。

_来源：[GitHub 的旧模式被 AI 击穿（InfoQ 翻译）](https://new.qq.com/rain/a/20260706A07ICS800)_

### 阿里宣布 7 月 10 日起全面禁用 Claude Code，改用 Qoder

因近期 Claude Code 被曝存在植入后门的安全风险，阿里巴巴经综合评估后将其列入高风险软件名单。自 7 月 10 日起，阿里将全面禁止内部员工在办公环境下使用 Claude Code，推荐使用自研的 Qoder 作为替代方案。禁令不仅限于 Claude Code，而是涵盖 Anthropic 旗下全线产品（Sonnet、Opus、Fable 等系列）。此前 Anthropic 曾指控阿里利用约 2.5 万个虚假账号对 Claude 进行大规模模型蒸馏攻击。

_来源：[阿里内部全面禁用Claude Code（科创板日报）](https://new.qq.com/rain/a/20260703A07GW800)_

### ByteDance 豆包和阿里 Qwen 将于 7 月 15 日关闭 AI Agent 功能

据 TechNode 报道，ByteDance 的豆包（Doubao）和 Alibaba 的 Qwen 将于 7 月 15 日起关闭 AI Agent 功能。这一决定与近期大厂对 AI Agent 安全性与成本管控的整体收紧趋势一致。腾讯、Meta、微软等科技巨头近期也开始给员工的 Token 用量设置上限，AI Agent 的规模化落地正从「野蛮生长」转向「合规可控」。

_来源：[TechNode 报道](https://technode.com/)_

### SvelteKit 发布 2.69.1 补丁版本

SvelteKit 发布了 2.69.1 版本，主要修复了两个安全相关的问题：修复了删除文件输入时可能导致的原型污染漏洞，以及修复了未处理的 Promise 拒绝问题。对于使用 SvelteKit 的开发者，建议尽快升级。

_来源：[SvelteKit Release（GitHub）](https://github.com/sveltejs/kit/commit/d89edcc5a37ffe45e768c3228683cd36ae1a4d73)_

### Mastra：现代 TypeScript AI Agent 框架持续活跃

Mastra 是近年来增长最快的 TypeScript AI 框架之一，GitHub 上已有超过 16,000 次提交。该项目专为 AI 驱动的应用和 Agent 构建而设计，提供完整的 TypeScript 类型安全和模块化架构。团队宣布将于 7 月 9 日举办实时语音 Agent 构建工作坊，前端开发者可将 Mastra 与 React/Vue/Svelte 等框架结合，快速构建 AI 原生应用。

_来源：[Mastra 官网](https://www.mastra.ai/) | [GitHub](https://github.com/mastra-ai/mastra)_

### Chrome 150 带来多项 CSS 新特性

Chrome 150 稳定版持续推送，带来多项值得前端关注的新特性：CSS 锚点定位增强（anchor() 函数可解析已转换元素的边界框）、新增 `::search-text` 伪元素自定义查找结果样式、`@scroll-state` 支持滚动方向响应式样式（实现导航栏上滑显现/下滑隐藏）、键盘滚动操作遵循 overscroll-behavior 设置。此外，DevTools 网络面板新增单个请求限速功能。

_来源：[Chrome 150 更新日志（爱纯净）](http://www.aichunjing.com/soft/2018-09-06/312.html)_

### Anthropic Claude Fable 5 深度评测引发社区热议

Anthropic 在 6 月 9 日发布的 Claude Fable 5 持续引发开发者讨论。作为首个面向公众的 Mythos 级模型，Fable 5 在 SWE-bench Verified 拿下 95.0%，SWE-bench Pro 达 80.3%，较前代 Opus 4.8 提升 11 个百分点。其 1M token 上下文和 128k 最大输出能力使其在长程 Agent 任务上表现突出。不过，该模型上线仅 4 天即被美国政府强制下线的事件，也为开发者的 AI 选型增添了不确定性。

_来源：[Claude Fable 5 深度分析（SegmentFault）](https://segmentfault.com/a/1190000047844896)_
