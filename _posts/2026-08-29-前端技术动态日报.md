AI 编程工具在 8 月末迎来一波密集发版，Claude Code、Copilot、Codex 等同档期更新，叠加 React 19.3 与 Chrome 153 的平台进展，今日重点如下。

### 一周 AI 编程工具密集发版（8/26–8/29）

8 月最后几天，主流 AI 编程 CLI 集中更新：Claude Code v2.1.251（8/28）、GitHub Copilot CLI v1.0.81（8/27）、OpenAI Codex CLI 0.150.0 / 0.150.1（8/26–27）、Antigravity CLI v1.1.22（8/27）、Kiro CLI v2.20.0（8/26）几乎在同一窗口落地。共同趋势是：会话可恢复、子代理/钩子能力增强、与 MCP / OpenTelemetry 的集成更深，以及更细粒度的权限与预算控制。

_来源：[Claude Code 更新日志](https://code.claude.com/docs/en/changelog) · [Claude Code Daily Briefing 8/29](https://claude-news.today/en/briefings/briefing-2026-08-29)_

### Claude Code v2.1.251：模型切换拦截钩子 + 实时子代理流 + 安全修复

作为本周最重磅的安全加固版本，v2.1.251 新增 `PreModelSwitch` / `PostModelSwitch` 钩子，可在模型切换发生时拦截、要求确认或仅记录；前台子代理的工具调用与结果现在能实时流式推送到 Remote Control 客户端。可观测性方面，`/usage` 增加 Spend limit 进度条、`/cost` 增加按会话的 prompt-cache 命中率 / 未命中 / 重缓存 token / 冷热状态明细。安全侧一次修复 5 个问题：符号链接文件工具越权读写、插件市场路径穿越、`Workflow` 脚本路径越权、Grep/Glob 在符号链接搜索路径下未应用拒绝规则，以及 Opus 5 在关闭 thinking 时高 effort 请求失败。

_来源：[Claude Code 官方更新日志](https://code.claude.com/docs/en/changelog) · [Havoptic：Claude Code v2.1.251](https://www.havoptic.com/r/claude-code-2.1.251)_

### GitHub Copilot CLI v1.0.81：插件仪表盘全员开放、崩溃后可恢复会话

Copilot CLI 8 月 27 日版本把插件仪表盘向所有人开放（运行 `/plugin`、`/mcp` 或 `/skills`），并带来崩溃 / 重启后自动恢复仍打开的会话。其他亮点：对齐 MCP 2026-07-28 规范、钩子可接收 OpenTelemetry trace 上下文并发出关联 span、为 Grok 4.6 增加 xhigh 推理档位、新增 Gemini 3.7 Flash 支持，以及 Windows 上受 Microsoft Entra ID 保护的远程 MCP 可通过 OS 认证代理（WAM）静默登录。

_来源：[GitHub Copilot CLI v1.0.81](https://www.havoptic.com/r/github-copilot-v1.0.81) · [NewReleases](https://newreleases.io/project/github/github/copilot-cli/release/v1.0.81)_

### OpenAI Codex CLI 0.150：任务互引、可点击 Markdown、中断钩子

Codex CLI 0.150.0（8/26）带来用 `@` 提及引用其它任务、从终端读写/创建/消息任务，`/copy` 增加完整响应 / 代码块 / 引用块的选取器，未命名终端任务自动生成标题，`Interrupt` 钩子可在顶层轮次被打断时执行命令或 MCP 处理器。0.150.1（8/27）修复远程 compaction 将保留图片计入 token 预算；最新的 0.151.0（8/29）进一步允许为可选 MCP 服务器配置发现宽限期，并让扩展在结果到达模型前检查或替换 MCP 工具结果。

_来源：[OpenAI Codex Changelog](https://developers.openai.com/codex/changelog)_

### React 19.3 临近：Fragment refs 与 ViewTransition 将稳定，Parallel transitions 已在生产使用

据 This Week in React #294，React 19.3 已近在眼前。Next.js 团队在 AMA 中确认 Fragment refs 与 `ViewTransition` 将在 19.3 稳定，并预览了更细粒度的预渲染与新数据获取原语；Parallel transitions 已在 Meta 生产环境使用，很可能随 React 与 React Native 双双进入 19.3。React Compiler 的 Rust 移植也持续推进，Oxlint、Biome、Bun 等已陆续接入自动 memoization。

_来源：[This Week in React #294](https://dev.to/sebastienlorber/this-week-in-react-294-react-compiler-tanstack-nextjs-gtkx-effect-rn-087-screens-rngh-4p6c)_

### Chrome 153 平台细节：WebGPU buffer_view 与 XML Rust 化

随 8/26–8/27 的稳定版推送，Chrome 153 引入 WebGPU 的 `buffer_view` WGSL 特性（在变量内重新解释数据，支持把一个 uniform/storage/workgroup 变量划分为多个逻辑变量并按不同类型解读），并把非 XSLT 场景的 XML 解析切换到内存安全的 Rust 实现，从源头减少内存安全类漏洞。结合本月其它能力（单轴滚动容器、Capability 元素、Iterator 辅助方法），Chrome 在 Web 平台标准上的推进依旧密集。

_来源：[Chrome Platform Status](http://chromestatus.com) · [Chrome Releases](https://releases.sh/google/product/chrome)_

_来源：[Chrome HTML-in-Canvas 官方文档](https://developer.chrome.com/blog/html-in-canvas-origin-trial) · [阮一峰周刊第 410 期](https://www.toutiao.com/article/7678876368171581986)_
