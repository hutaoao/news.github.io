周末技术圈依然活跃，AI编程领域迎来重磅新品，跨端工具链也有值得关注的更新。以下是 7 月 25 日核心动态。

### Anthropic 发布 Claude Opus 5：性能逼近旗舰 Fable 5，价格砍半

7 月 25 日凌晨，Anthropic 正式发布 Claude Opus 5，定位「深思熟虑且积极主动」的模型。其智能水平接近旗舰 Fable 5，但 API 定价仅为后者的一半——输入 $5/M tokens、输出 $25/M tokens，与前代 Opus 4.8 保持一致。在 Agentic 编码测试 Frontier-Bench 中，Opus 5 得分 43.3%，达到 Opus 4.8 的两倍以上，单任务成本反而更低。针对前端开发者而言，这意味着可以以更低成本使用顶级 AI 辅助编程能力，对 Cursor、Claude Code 等工具的日常使用体验提升显著。

_来源：[Anthropic 官方](https://www.anthropic.com/) | [InfoQ](https://www.infoq.com/news/4/)_

### Meta 将 React Compiler 移植到 Rust，合入主仓库

据 InfoQ 报道，Meta 已将 React Compiler 的 Rust 版本集成到 React 主仓库中。该版本通过自动记忆化组件，显著提升构建速度并更好地与基于 Rust 的 JavaScript 工具链配合。据报道，部分场景下编译速度提升达 50%，且公共 API 保持不变，开发者可平滑升级。这一举措延续了前端工具链「Rust 化」的浪潮，继 Turbopack、Biome（原 Rome）之后，React 自身也加入了 Rust 阵营。

_来源：[InfoQ](https://www.infoq.com/news/4/)_

### Firefox 153 稳定版上线：Windows 端首增 HDR 视频播放

Mozilla 于 7 月 22 日发布 Firefox 153 稳定版，最大亮点是为 Windows 10/11 用户新增 HDR 视频播放支持。开发者视角方面，该版本还带来了 Intl.Locale 信息方法、IndexedDB getAllRecords()、Source Phase Imports 以及 WebAssembly JSPI 等新特性，进一步缩小了与 Chrome 在 Web 标准支持上的差距。

_来源：[Mozilla 官方博客](https://www.mozilla.org/) | [Web Standards](https://web-standards.dev/news/2026/07/firefox-153/)_

### Claude Code 已整合 Rust 重构版 Bun

开发者 Simon Willison 在检查 Claude Code v2.1.181 可执行文件时，发现其中包含「Bun v1.4.0」字样及大量 Rust 源文件引用，证实 Claude Code 已整合 Rust 重写后的 Bun 运行时。此前 Bun 创始人 Jarred Sumner 在 Claude Fable 5 模型帮助下，耗时 11 天、花费 16.5 万美元，将 Bun 从 Zig 完全重写为 Rust。此次整合使得 Claude Code 的 Linux 平台启动速度提升约 10%。这也是 AI 辅助大规模代码重构的里程碑案例。

_来源：[IT之家](https://www.ithome.com/) | [Claude Code GitHub](https://github.com/anthropics/claude-code)_

### GitHub Issues 导航架构大改造：客户端缓存 + 预取，即时导航提升至 22%

InfoQ 报道，GitHub 重新设计了 Issues 背后的客户端导航架构，引入客户端缓存、预测性预取及基于 Service Worker 的请求处理机制，将即时导航体验比例从 4% 提升到 22%。这一案例对大型前端 SPA 应用优化具有参考价值——通过减少重复网络请求和客户端初始化延迟，显著改善频繁操作工作流的体验。

_来源：[InfoQ](https://www.infoq.com/architecture-design/news/3/)_

### GitHub Copilot 全面转向按 Token 计费

GitHub 自 6 月起已将 Copilot 全面从固定订阅制转为基于「GitHub AI Credits」的按量计费模式。代码补全免费，Chat 和 Agent 功能消耗积分，超出套餐额度后需购买额外积分。这意味着重度使用 Copilot 的开发者月费可能从此前的固定 $10 上涨数倍，业界反响不一。FidoNews 报道有开发者反馈月费从 $10 涨至 $47。这一变化也成为 AI 开发工具商业模式的重要风向标。

_来源：[CSDN](https://blog.csdn.net/Leinwin/article/details/160829768) | [FidoNews](https://www.fidonews.org/)_

### CSS 新属性 text-fit：自动缩放排版实战

Web Standards 在 7 月 20 日发布了一篇实操文章，深入介绍新的 CSS `text-fit` 属性。该属性可实现字体的自动缩放适配，无需 JavaScript 辅助即可让标题在不同的容器尺寸下自动调整字号，有望简化响应式排版方案。该属性属于 CSS 容器查询能力的延伸，正逐步获得浏览器支持。

_来源：[Web Standards](https://web-standards.dev/news/2026/07/playing-with-text-fit/)_
