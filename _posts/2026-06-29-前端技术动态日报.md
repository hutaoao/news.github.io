本周前端技术生态迎来多项里程碑式更新。

### TypeScript 7.0 RC：Go 编译器时代加速到来

微软于 6 月 18 日发布 TypeScript 7.0 Release Candidate，核心编译器移植至 Go 框架，性能提升约 10 倍，且完全兼容 6.0 语义。社区反馈热烈，许多开发者对 Go 重写带来的构建速度提升充满期待。正式版预计在未来数周内发布。

_来源：[IT之家 - TypeScript 7.0 RC](https://so.html5.qq.com/page/real/search_news?docid=70000021_8026a34d03325152)_

### Babel 8.0 正式发布：八年磨一剑

Babel 团队宣布 8.0 版本正式发布，距离 7.0 已过去八年。v8.0 全面转向 ESM，默认目标从 ES5 升级至约 ES2023，是一次彻底的现代化升级。尽管 SWC 和 Oxc 等 Rust 工具崛起，@babel 包的周下载量依然增长 380 倍。

_来源：[Babel 官方公告](https://babeljs.io/blog)_

### TypeScript 7.0 与 Babel 8.0 对前端生态的影响

TypeScript 7.0 的 Go 重写方案预计将彻底改变大型项目的构建体验，而 Babel 8.0 的 ESM-only 转型意味着旧版工具链需同步升级。两者的接连发布标志着 JavaScript 转译与类型检查工具链进入全新阶段。

### Astro 7.0 发布：Rust 管道全面接管

热门 Web 框架 Astro 7.0 正式发布，获得更快的构建速度。.astro 编译和 Markdown/MDX 处理现走 Rust 管道，高级路由功能让开发者完全控制请求处理流程。

_来源：[Astro 官方博客](https://astro.build/blog/)_

### Vite 8.1 引入「打包开发模式」，大型项目提速 15 倍

Vite 8.1 引入了打包开发模式（bundled dev mode），让包含大量模块的应用启动和热重载更快。在包含 10,000 个组件的测试应用上，速度提升达 15 倍。这是 Vite 团队继 Rolldown 统一引擎后的又一次性能大跃进。

_来源：[Vite 官方发布说明](https://vite.dev/blog/)_

### Rsbuild 2.1 发布，集成 Rust 版 React Compiler

字节跳动开源的构建工具 Rsbuild 发布 2.1 版本，现包含基于 Rust 的全新 React Compiler 实现，并新增对 TanStack Start 的支持。这一更新进一步缩小了 Rspack 生态与 Vite 生态的性能差距。

_来源：[Rsbuild 发布说明](https://rsbuild.dev/)_

### MDN 推出官方 MCP 服务器

MDN 发布了官方 MCP（Model Context Protocol）服务器，专为编程智能体提供更好的访问 MDN 最新 JavaScript 和前端文档的能力。这意味着 AI 编码工具现在可以通过标准协议直接查询 MDN 文档，有望显著提升 AI 生成代码的准确性。

_来源：[MDN 官方公告](https://developer.mozilla.org/)_

### Deno 2.9 发布，支持创建跨平台桌面应用

Deno 2.9 已发布，主打特性是支持创建跨平台桌面应用。开发者可以使用 Web 技术（HTML、CSS、JavaScript/TypeScript）构建原生桌面应用，为 Electron 和 Tauri 生态带来新的竞争者。

_来源：[Deno 官方博客](https://deno.com/blog)_

### Next.js 16.3 预览版：解决导航卡顿难题

Next.js 16.3 预览版发布，针对服务器组件常见的导航卡顿问题提供了新方案。新的可选行为在保留服务器端优势的同时，让导航体验媲美 SPA。官方还创建了 Agent 技能，帮助现有项目采用这些新特性。

_来源：[Next.js 官方博客](https://nextjs.org/blog)_

### CSS 新工具：Prop For That 让 CSS 获取 JS 动态值

开源工具 Prop For That 发布，为 CSS 提供通常需要 JavaScript 才能获取的值（如指针位置、时间、滑块值）。在 HTML 中添加属性，实时值就会以 CSS 自定义属性的形式出现，架起了 JS 与 CSS 之间的桥梁。

_来源：[Prop For That 官网](https://propforthat.com/)_

### FullCalendar 7.0 发布：支持 Angular 22

功能完备的 JavaScript 日历组件 FullCalendar 发布 7.0 版本。支持 React、Vue 和 Angular（v7.0 新增 Angular 22 支持），也可用纯 JavaScript 使用。

_来源：[FullCalendar 发布说明](https://fullcalendar.io/docs/release-notes)_

### pnpm 11.7 发布：新增 --dry-run 选项

pnpm 11.7 发布，pnpm install 新增 --dry-run 选项，--frozen-store 新增对只读包存储的支持，进一步优化了 monorepo 场景下的包管理体验。

_来源：[pnpm 发布说明](https://pnpm.io/)_
