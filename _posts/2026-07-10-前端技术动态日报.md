今日前端圈迎来重磅一周收官：TypeScript 7.0 正式登场、ECMAScript 2026 获批、谷歌为 Web AI 推理送来提速利器，同时 OpenAI 战略收缩 Atlas 浏览器等事件引发广泛讨论。

### TypeScript 7.0 正式版发布：编译性能飙升 10 倍，14 年来最大变革

微软于 7 月 9 日正式推出 TypeScript 7.0，这是该语言诞生 14 年以来最具革命性的版本。TypeScript 编译器核心从 JavaScript/TypeScript 完全移植到了 Go 语言，得益于原生代码速度和共享内存并行机制，大型代码库上的编译性能提升约 10 倍，编辑器响应速度从 17 秒缩短到 1.3 秒以内。开发者可通过 npm 上的 typescript 包直接安装体验。

_来源：[微软 TypeScript 官方博客](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/)_

### ECMAScript 2026 正式获批：JavaScript 迎来第 17 版规范更新

ECMA International 于 6 月 30 日正式批准 ECMAScript 2026，这是 JavaScript 的第 17 个年度版本。新规范在多个领域增加了新方法：数学运算新增 `Math.sumPrecise` 用于高精度求和；`Array.fromAsync` 支持从异步可迭代对象构建数组；`Iterator.concat` 实现多迭代器顺序连接；`Error.isError` 新增错误类型识别；`JSON.rawJSON` 和 revivers 增强参数提供了更精细的 JSON 控制能力。

_来源：[腾讯新闻](https://new.qq.com/rain/a/20260710A002R500)｜[ECMA International](https://ecma-international.org/)_

### 谷歌发布 LiteRT.js：Web AI 推理最高提速 3 倍

谷歌 7 月 9 日发布 LiteRT.js 库，旨在替代 TensorFlow.js 的 JavaScrip 内核方案。LiteRT.js 采用 WebAssembly 技术，结合 WebGPU 与 WebNN 等硬件加速能力，让浏览器中的 AI/ML 推理性能大幅跃升。在搭载 M4 芯片的 MacBook Pro 上测试，相较现有方案速度提升达 3 倍，旧硬件上的表现也有显著改善。

_来源：[IT之家](https://new.qq.com/rain/a/20260710A03GNZ00)｜[Google AI Edge 博文](https://ai.google.dev/)_

### OpenAI 宣布关停 Atlas 独立浏览器，AI 浏览功能并入 ChatGPT 桌面端

OpenAI 本周宣布关闭其运营不足一年的独立桌面浏览器 ChatGPT Atlas，设定 2026 年 8 月 9 日为正式下线日期。Atlas 的 AI 浏览能力（页面感知、跨站任务执行等）将被重新整合进新版 ChatGPT 桌面应用中。此举被视为从「造新浏览器」到「嵌入现有浏览器」的 180 度战略转变——Chrome 占据全球 72% 的桌面浏览器份额，OpenAI 选择将 AI 核心寄生在现有用户路径上。

_来源：[9to5Mac](https://9to5mac.com/)｜[TechCrunch](https://techcrunch.com/)_

### 工信部警示 Claude Code 存在安全后门隐患

2026 年 7 月 8 日，工信部网络安全威胁和漏洞信息共享平台发布的 AI 编程工具风险提示中，将 Claude Code 的危害等级评定为「严重」。通报指出，受影响的 Claude Code 2.1.91 至 2.1.196 版本在未经用户同意的情况下，内置监控机制会向远程服务器回传用户地域信息、身份标识等敏感数据。工信部建议相关单位和用户立即排查并升级至安全版本。

_来源：[腾讯网](https://so.html5.qq.com/page/real/search_news?docid=70000021_4476a4e1e5f31652)_

### Bun 从 Zig 到 Rust 的重写持续引发热议

围绕 Bun 从 Zig 语言迁移到 Rust 的重写工程，本周继续发酵。Jarred Sumner 透露这次重构耗时约 6 天涉及 96 万行代码，其中大量代码由 Claude Code 协助完成。但这一循环也引发了开发者社区的广泛讨论——Claude Code 此前被 Bun 的内存泄漏问题困扰，而 Anthropic 又让 Claude 反过来重写 Bun。Bun v1.4.0 以 Canary 版本发布，修复 128 个错误，运行速度提升约 2%~5%。

_来源：[CSDN](https://blog.csdn.net/2501_91883294/article/details/161057398)｜[IT之家](https://so.html5.qq.com/page/real/search_news?docid=70000021_8436a51f35b36752)_

### Chrome DevTools MCP 协议强势出圈，AI 编程助手获浏览器调试能力

Chrome DevTools MCP 项目本周在 GitHub 持续走高。它通过 Model Context Protocol 协议让 Claude、Cursor、Copilot 等 AI 编程助手直接操控 Chrome 浏览器的 DevTools，从页面导航到性能分析、从网络请求检查到内存调试，全面开放。这标志着 AI 原生协作开发工具链正在快速成型，与 GitButler、Letta-code 等项目共同指向「AI 即开发环境」的新范式。

_来源：[CSDN](https://blog.csdn.net/Yunyi_Chi/article/details/158433071)｜[GitHub](https://github.com/Coin-Collect/chrome-devtools-mcp)_

### CSS light-dark() 函数深度探讨：暗黑模式的正确打开方式

本周前端社区围绕 CSS `light-dark()` 函数展开了新一轮讨论。该函数能显著简化暗黑模式的样式设置，但需搭配 `color-scheme: light dark;` 使用，且其行为与 `prefers-color-scheme` 存在微妙差异——前者跟随 `color-scheme` 属性而非操作系统设置，两者适用于不同的主题切换场景。Google DevRel 的 Una Kravets 也撰文介绍了 `light-dark()`、`contrast-color()` 与样式查询的组合使用。

_来源：[tool.lu](https://tool.lu/article/7wn/detail)｜[Una Kravets Blog](https://una.im/)_

### 鸿蒙 HarmonyOS 7 设备占比持续上升，开发者预览版推进中

华为自 HDC2026 发布 HarmonyOS 7 后，开发者预览版的招募工作持续推进。截至 7 月 8 日数据，HarmonyOS 7.0.0 Beta1（API 26）的设备占比已升至 0.22%，而 HarmonyOS 6.1.1 升至 36.73%。纯血鸿蒙终端已突破 7000 万台，生态内原生应用超 40 万款。
