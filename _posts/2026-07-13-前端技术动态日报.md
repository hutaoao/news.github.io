本周一，前端圈虽无重磅大版本发布，但几个值得关注的动态值得一一记录。

### JetBrains IDEA 2026.1 免费开放核心前端功能

JetBrains 宣布从 IDEA 2026.1 版本开始，将原本仅限 Ultimate 订阅用户使用的核心 JavaScript、TypeScript、HTML 和 CSS 功能免费开放给所有用户，包括 Community 版。这意味着 IntelliJ IDEA Community 用户现在也能享受参数提示、智能代码补全、重构等前端开发关键功能，对广大开源和独立开发者是一大利好。

_来源：[腾讯网](https://so.html5.qq.com/page/real/search_news?docid=70000021_0046a53289617952)_

### Cursor 正在开发通用 AI 智能体「Sand」，对标 Claude Cowork

据外媒报道，代码编辑器 Cursor 正在开发一款名为「Sand」的通用 AI 智能体，旨在与 Anthropic 的 Claude 和 OpenAI 的 ChatGPT 在更广泛的生产力场景中竞争。Cursor 自 4 月起向 SpaceXAI 租赁算力，启动了这款新智能体的研发，产品已于 6 月下旬在公司内部上线测试。这标志着 Cursor 从单一编程工具向通用 AI 平台迈出的重要一步。

_来源：[腾讯网](https://so.html5.qq.com/page/real/search_news?docid=70000021_2156a54a4f453352)_

### GitHub 的旧模式被 AI 击穿，Cursor、GitLab、Zed 各自开打

外媒报道分析了当前代码托管与协作平台的格局变化。GitHub 的「PR + Review」传统开发模式正受到以 Cursor、GitLab、Zed 等新一代工具的冲击。AI 辅助编程让「Agent 写代码、人审阅」成为新常态，GitHub 面临其核心工作流被替代的风险。文章深入讨论了开发平台如何在 AI 时代转型。

_来源：[腾讯网](https://so.html5.qq.com/page/real/search_news?docid=70000021_2046a54a4ee27852)_

### Django 开发者调查 2026 今日截止

Django Software Foundation 与 JetBrains 合作的 2026 年 Django 开发者调查于今日（7 月 13 日）正式截止。调查旨在了解 Django 在全球的使用情况，帮助指导未来技术和社区决策。目前已收集近 4000 份回复，数据结果预计将在后续公布。

_来源：[Django 官方博客](https://www.djangoproject.com/weblog/)_

### Vue x Vite 开发者大会 2026 倒计时一周

Vue x Vite 开发者大会 2026 将于 7 月 18 日在上海举办，距离开幕仅剩一周。大会由尤雨溪（Vue.js 和 Vite 作者）领衔，另有黄玄等嘉宾出席。会议将聚焦 Vue 和 Vite 生态最新进展，是今年国内前端圈最重要的技术盛会之一。

_来源：[VueConf 官网](https://vueconf.cn/)_

### Svelte 5.40.2 修补版本发布

Svelte 团队发布了 5.40.2 补丁版本，这是 Svelte 5 系列的又一增量更新。虽然此次更新以 bug 修复为主，未引入重大新功能，但 Svelte 5 生态正在稳步成熟，社区组件库数量持续增长。

_来源：[GitHub Release](https://github.com/sveltejs/svelte/releases/tag/svelte@5.40.2)_

### 用 Claude Code 重写 SQL 解析器，性能暴涨 70 倍

PostHog 团队分享了使用多个并行 Claude Code 会话重写其 SQL 解析器的经验。通过 AI Agent 的自动化代码生成与人工验证闭环，他们在不到一周内将 SQL 解析性能提升了 70 倍，展示了 AI 编程工具在前端之外的后端/基础设施领域的巨大潜力。

_来源：[PostHog 博客（infoQ 编译）](https://so.html5.qq.com/page/real/search_news?docid=70000021_5496a5479e669352)_
