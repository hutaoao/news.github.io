周日的重点几乎全被 AI 编程工具承包：OpenClaw 憋了七周放出史上最大版本，OpenAI 宣布对 Cursor 断供，GitHub Copilot 同日下线六款模型；工具链那边 Rspack 2.2、pnpm 12 与 Solid 2.0 RC 也集中落地。

### OpenClaw 2.0 发布：933 名贡献者、1.6 万个 PR，史上最大一次更新

开源个人 AI 助手 OpenClaw 在停更近七周后放出 2.0（版本号 v2026.8.1），官方称合并了超过 1.6 万个 PR，约占项目历史合并总量的一半，933 名贡献者中有 569 人是首次提交。团队原本只想简化安装流程、重做浏览器端，结果越改越深，最终波及会话执行、浏览器控制、记忆系统、自动化、插件和安全机制。浏览器端被提升为「一等入口」：Control UI 启动时间从约 1.6 秒降到 575 毫秒，请求数从 140 降到 45；新增 Session Rail 进度卡、会话全文检索，以及可固定到仪表盘的交互式结果。

_来源：[The Decoder：OpenClaw 2.0](https://the-decoder.com/openclaw-2-0-brings-simplified-setup-a-rebuilt-browser-app-and-multiplayer-sessions/) · [上海证券报：强化跨终端协作能力](https://finance.eastmoney.com/a/202608313860335320.html) · [腾讯云开发者社区](https://cloud.tencent.com/developer/news/4532976)_

### OpenClaw 2.0 的共享云会话与两处破坏性迁移

2.0 最实质的结构变化是「多人 + 多机」。Shared Cloud Sessions 允许团队成员带着已有上下文进入同一任务或中途接手；会话可运行在本地 Gateway、已配对设备，或通过 Crabbox 租用的临时云机器上，而 Provider 凭据始终留在 Gateway、不下发到远端执行机。安全侧新增 Private Credential Request（遮罩输入密码/Token，避免进入聊天记录和模型上下文）、Active Memory（跨会话调用历史对话）与 Self-learning（把任务中积累的方法转成新 Skills）。升级需注意两处破坏性变更：内置 OpenProse 插件与 `/prose` 命令被移除，旧的 `codex/` 与 `openai-codex/` 模型路由需要用 `openclaw doctor --fix` 迁移。

_来源：[RuntimeWire：OpenClaw 2.0 rebuilds the personal agent](https://runtimewire.com/article/openclaw-2-browser-multiplayer-agent) · [OpenClaw 发布说明](https://openclaw.ai/)_

### OpenAI 宣布终止向 Cursor 供应模型，11 月 12 日生效

SpaceX 以约 600 亿美元收购 Cursor 母公司 Anysphere 并完成交割后，OpenAI 触发控制权变更条款，宣布终止直接供模：直连权限 2026 年 11 月 12 日关闭，包括尚未发布的 Astra 在内的新模型也不再提供，缓冲期后开发者只能自带 API Key。OpenAI 的理由是「无法确认 SpaceX 会遵守服务条款」，并援引了 Twitter 曾违反合同、马斯克在宣誓下承认 xAI 蒸馏过 OpenAI 训练数据等先例。Cursor 方面回应称 OpenAI 只占其流量的 5%，且不认为该决定是最终的。对前端团队来说，这是一记明确的供应链风险提醒：选 IDE 时要评估背后的模型供给与战略卡位。

_来源：[OpenAI：Our decision on Cursor following its acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/) · [Hacker News 讨论](https://news.ycombinator.com/item?id=49486172)_

### GitHub Copilot 于 8 月 31 日下线六款模型

GitHub 补齐了 8 月模型弃用清单，六款模型在 8 月 31 日从 Copilot 的全部界面（chat、代码补全、代码审查、agent 模式）下线：Gemini 3.1 Pro（建议迁到 Gemini 3.6 Flash）、Claude Opus 4.5 与 4.6（建议迁到 Opus 4.7 / 4.8 / 5）、Claude Sonnet 4.5（迁到 Sonnet 5）、Claude Sonnet 4.6（个人年付订阅者例外，避免没有 Sonnet 可用），以及 Raptor mini（无替代）。Business 与 Enterprise 管理员需要在切换前检查模型策略，否则团队依赖的模型可能静默失效。

_来源：[GitHub Changelog：Upcoming August 2026 model deprecations](https://github.blog/changelog/) · [AI Coding News, August 29, 2026](https://oday-bakkour.com/blog/ai-coding-news-august-29-2026-claude-code-model-switch-hooks)_

### xAI 发布 Grok Code Fast 1：编程模型打起「快且便宜」价格战

xAI 于 8 月 29 日推出面向 Agentic 编程工作流的推理模型 Grok Code Fast 1，SWE-bench Verified 得分 70.8%，上下文 256K，定价为输入 0.2 美元 / 百万 token、输出 1.5 美元 / 百万 token，并在 Cursor、GitHub Copilot、Windsurf、Cline、Kilo Code 等主流 IDE 限时免费开放。编程模型正式进入性价比分发阶段——用补贴抢开发者入口，对 Claude Code、Cursor 等形成正面争夺。

_来源：[8月31日 AI Coding 与具身智能重点动态](https://www.toutiao.com/a7680013306836386358)_

### htmx 4.0.0 发布：内部迁到 fetch()，属性继承改为显式

htmx 4.0 于 8 月 28 日发布，登上 Hacker News 首页。这是八个月工作的结果，内部从 XMLHttpRequest 全面迁移到 `fetch()`（对多数用户透明），带来流式 HTML 支持。三个主要变化：属性继承从「默认隐式」改为「默认显式」（需写成 `hx-confirm:inherited`，这是最大的迁移负担，`hx-disinherit` 等不再需要）；事件名统一为 `htmx:phase:action[:sub-action]`（如 `htmx:afterRequest` → `htmx:after:request`，`htmx:xhr:*` 移除，校验类事件让位给原生表单校验）；历史记录不再使用 localStorage 快照，后退时重新拉取页面。新特性方面原生支持 morphing swaps（改进版 idiomorph 算法）和 `<hx-partial>` 标签，并新增 `hx-preload`、`hx-download`、`hx-alpine-compat`、`hx-live` 等扩展。官方提供了 `npx htmx.org@4.0.0 upgrade-check` 扫描工具和四个 LLM skills 文件；npm 上 2.x 仍为 `latest`，4.0 挂在 `next` 直到 2027 年初。

_来源：[htmx 4.0.0 has been released!](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released) · [Hacker News 讨论](https://news.ycombinator.com/item?id=49478178)_

### Claude Code 桌面端打通终端会话：新增 /resume 跨端续接

Anthropic 为 Claude Code 桌面端新增 `/resume` 命令，可恢复此前在终端开启的历史会话，对话记录与上下文一并迁移，与终端原有的 `/desktop` 命令形成双向通道。恢复后仍支持 `/rewind` 检查点回退，跨端接手不会破坏此前进度。目前限制是桌面端新建的会话尚无法回传终端。同期 Claude Code CLI 也上线了额度恢复自动续跑，并修复了会话标题丢失等问题。

_来源：[腾讯研究院 AI 速递 20260831](https://www.sohu.com/a/1069745836_455313)_

### 本周工具链：Rspack 2.2、pnpm 12、Solid 2.0 RC、Node.js 26.8.0

据「栗子前端技术周刊」第 144 期（2026.08.24–08.30）汇总：**Rspack 2.2** 发布，含 30 多项性能优化（构建时间缩短、HMR 改进、模块 ID 更短），新特性包括 `import.meta` 改进、支持 Browserslist Baseline 及更多平台；**pnpm 12** 发布，Rust 重写版本正式稳定，v11 的命令、参数与锁文件格式基本沿用，全局 node 版本跟随项目锁定版本——注意 npm 的 `latest` 标签仍指向 pnpm 11，需要 `pnpm self-update next-12` 升级；**Solid 2.0 RC** 把异步内置进响应式依赖图，异步数据可直接通过普通 memo 流转，`createResource`、`batch`、`startTransition` 均已移除，SolidStart 退役、能力改为通过 Vite 插件的 `start: true` 开启且 API 已冻结；**Node.js 26.8.0** 无需第三方依赖即可读写 ZIP 压缩包，REPL 新增基础语法高亮，随后发布 26.8.1 修复版本字符串异常。

_来源：[栗子前端技术周刊第 144 期](https://juejin.cn/post/7679542577553506358)_

### 研究：换 harness 比换模型更能提升 Agent 成功率

微软 AutoSaddler 论文把 agent harness 当作代码来管理，结果显示调整 harness（提示、工具配置、控制逻辑）对成功率的影响大于更换模型——GAIA2 +9.0、SWE-Bench Pro +9.6，并提出了「Harness Card」披露标准。同期社区讨论也在收敛到同一结论：Agentic 编码的瓶颈不是生成速度或提示词质量，而是反馈回路速度，团队应把投入从「写更好的 prompt」转向「设计更好的 harness」（测试环境、类型检查门禁、静态分析流水线）。

_来源：[8月31日 AI Coding 与具身智能重点动态](https://www.toutiao.com/a7680013306836386358) · [Next.js prefetch stabilized, Go 1.25 flight recorder lands](https://dev.to/devsignal/nextjs-prefetch-stabilized-go-125-flight-recorder-lands-13k3)_
