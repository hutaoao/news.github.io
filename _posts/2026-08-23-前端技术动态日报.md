周末这天 CSS 唱主角——浏览器把一批过去要靠 JS 撑起来的能力搬进了原生。以下是 2026-08-23 值得关注的技术动态。

### Chrome 152 带来 7 个媒体伪类，视频播放器可零 JS 管理状态

即将于 8 月 25 日进入稳定版的 Chrome 152，为媒体元素新增 7 个伪类：`:playing`、`:paused`、`:seeking`、`:buffering`、`:stalled`、`:muted`、`:volume-locked`。过去每个自定义视频播放器都要靠一堆事件监听器在 JS 里维护一份「影子状态」再同步成 class，一旦漏事件就会失同步。现在配合早已 Baseline 的 `:has()`——`.player:has(video:paused) .play-icon { display:block }`——容器可直接查询自身后代的媒体状态并驱动样式，播放/暂停图标切换、缓冲 spinner、静音状态全部无需 JS。需注意它目前是 Chrome-only、尚非 Baseline，是 Interop 2026 focus area，Firefox/Safari 今年承诺跟进，生产环境仍要写降级路径。

_来源：[Code With Seb](https://www.codewithseb.com/blog/css-media-pseudo-classes-zero-js-video-player)_

### CSS 原生 masonry 多引擎推进中，但落地进度仍参差

8 月里 CSS 原生瀑布流（masonry）在多引擎上有了实质进展，它被整合进 CSS Grid 布局模型，通过 `grid-template-rows: masonry` 让浏览器原生计算变高元素的排布，相比过去的 JS 计算库或脆弱的多列 hack，能换来即时渲染、正确 Tab 顺序与零布局偏移。不过各引擎进度并不统一：Chrome 已可用、Firefox 仍需开 flag、Safari 仅在 TP 中，尚未形成跨引擎一致的稳定实现，更未进入 Baseline。生产环境建议用 `@supports (grid-template-rows: masonry)` 做降级，回退到多列或 JS 方案，避免「写了 masonry 却在部分浏览器塌成单列」。

_来源：[Web Professionals Global - August 2026 Desktop View](https://webprofessionalsglobal.org/august-2026-desktop-view)_

### CSS `if()` 推进中但仍是 Chromium-only，`:open` 已进入 Baseline

本月 CSS 写入能力最受关注的是 `if()` 内联条件函数与 `:open` 伪类，但两者成熟度不同。`if()` 允许在声明里对自定义属性、容器、媒体特性求值实现运行时条件样式，对企业级设计系统的 token 换肤很有吸引力——但目前仅 Chromium（Chrome 137+/Edge 137+）实现、被 MDN 标记为实验性，Firefox 与 Safari 尚未跟进，且不具备优雅降级能力，因此还远未进入 Baseline，写静态默认值并配合 `@supports` 守护才是稳妥做法。相比之下，`:open` 伪类（命中展开态的 `<details>`/`<dialog>`/popover）已在主流引擎稳定落地并进入 Baseline，可用它替代 `.is-active` / `[data-state=open]` 的手动切换。「浏览器补齐 JS 框架多年来靠 observer 和 listener 伪造的能力」是 2026 年的主旋律，但节奏快慢不一。

_来源：[Web Professionals Global - August 2026 Desktop View](https://webprofessionalsglobal.org/august-2026-desktop-view)_

### OpenAI Codex CLI rust-v0.149.0：终端里的 Agent 仪表盘

8 月 20 日发布的 Codex CLI（rust-v0.149.0）是迄今最偏工作流的一次更新。新增交互式 Agent 仪表盘，可在终端内搜索、启动、打开、重命名、停止后台任务而无需离开命令行；`/cd`、`/pwd`、`/cwd` 支持会话中途管理工作目录，`codex queue` 向已运行的本地/远程会话发消息；Vim 模式补齐 `cw`、`c$`、`cc` 等真实编辑动作；`codex doctor` 现在能诊断端点防护、网络/代理故障与更新连通性。安全侧强化了插件隔离，且当策略更新失败时直接拒绝网络访问。

_来源：[AI Coding News (Aug 23)](https://oday-bakkour.com/blog/ai-coding-news-august-23-2026-copilot-slack-teams-claude-code)_

### Claude Platform 上线 Browser Use、Computer Use 与 Skills / Files API

Anthropic 宣布 Claude Platform 的 Computer Use、Skills API 与 Files API 全面 GA，并推出全新的 Browser Use 工具。Computer Use 更新后可在单次模型调用中执行多个连续操作，大幅减少任务耗时与调用次数，并达到 HIPAA 合规、可用于受监管的医疗健康负载。Browser Use 是本次亮点，引入网页结构解析能力，能直接识别并交互页面上的特定输入框或按钮，比传统截图点击更精准。Skills API 允许企业上传专有技能文件夹（指令、脚本、模板）在 Claude 沙箱中安全运行；Files API 提供稳定文档存储，速率限制提升 5 倍，每组织享 1TB 专用存储。

_来源：[AIbase](https://www.aibase.com/news/30522)_

### Ant Design 6.6.1：可访问性与交互路径集中修复

8 月 17 日发布的 Ant Design 6.6.1 是一次以质量为主的补丁。可访问性侧改进了 Upload、Modal、Notification、Form、Carousel、RangePicker、Collapse 的可访问名称与读屏行为，并调整繁体中文、冰岛语、蒙古语文案；功能侧新增 Carousel 箭头本地化、Listy 迁移与拖拽能力、BorderBeam 跟随动态圆角。修复覆盖异步 Upload 删除、Anchor 重复回调、Form 抖动与 offset、Table `rowSpan` hover、Transfer 双触发、Select 键盘清除等大量交互路径。使用 6.6.0 的项目建议完成表单与无障碍回归后升级。

_来源：[Ant Design 6.6.1 Release](https://github.com/ant-design/ant-design/releases/tag/6.6.1)_

### 阿里开源 Qwen-UI-Agent：面向真机的 GUI 智能体基座

阿里推出以真实世界为中心的 GUI 智能体基座模型 Qwen-UI-Agent，覆盖移动端、桌面端、网页端与深度搜索环境。为弥合「模拟与现实」差距，团队构建了覆盖 100+ 真机、150+ 应用的真实移动环境用于任务构建与训练，并推出含 400+ 任务的 MobileWorld-Real 真机基准。模型不仅支持常规 GUI 操作，还能直接执行命令行、单次决策输出批量动作以缩短执行轨迹；面对违法或高风险请求直接拒绝，涉及支付、数据删除、隐私授权等敏感场景时在关键步骤暂停等待确认，并支持 100 步以上轨迹的在线强化学习训练。

### CSS 安全提醒：邮件里的 CSS 可绕过 sanitizer 窃取 token

This Week in React 引用的一项研究提醒开发者：精心构造的 CSS 可以绕过邮件客户端的 sanitizer，进而窃取 token。这类攻击不依赖 JavaScript，纯靠 CSS 选择器与属性行为泄露信息，容易被传统「只防脚本」的净化策略漏过。在富文本/邮件渲染、以及任何允许用户注入样式的场景中，值得把 CSS 也纳入内容安全的审查范围。

_来源：[This Week In React #294](https://dev.to/sebastienlorber/this-week-in-react-294-react-compiler-tanstack-nextjs-gtkx-effect-rn-087-screens-rngh-4p6c)_
