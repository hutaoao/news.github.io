## 头条

### Rspack 2.0 正式发布：纯 ESM 核心、依赖骤减、性能再提升

字节跳动旗下基于 Rust 的前端打包工具 Rspack 正式发布 2.0 版本。此次升级亮点颇多：@rspack/core 转为纯 ESM 包发布，移除 CommonJS 构建；@rspack/dev-server 依赖项从 192 个锐减至 **1 个**，安装体积从 15MB 压缩至 1.4MB，这一细节在 Hacker News 上引发热议，被评论为「理念层面的转变，而不仅仅是基准测试」。性能方面，在 10000 组件的 React 项目中启用持久化缓存后，生产构建从 5.6 秒降至 1.4 秒，HMR 降至 118ms。此外 2.0 还实验性支持了 React Server Components。当前 Rspack 每周 npm 下载量已从 1.0 时代的 10 万飙升至超 500 万。迁移需注意 Node.js 需 20.19+ 或 22.12+。

_来源：[InfoQ](https://www.infoq.com/news/2026/07/rspack-2-release/) | [Rspack 官网](https://rspack.rs/)_

### 微软为 Node.js 推出 WinRT 动态投影工具：JS/TS 直接调用 Windows 原生 API

微软发布了 Node.js 的 Windows Runtime 语言投影工具（Public Preview），让 Electron 应用及普通 Node.js 应用开发者能够直接通过 JavaScript 或 TypeScript 调用受支持的 Windows 原生 API。该工具可读取 Windows 提供的 API 元数据，自动生成对应的 JavaScript 接口代码以及 TypeScript 类型定义，随后由共享运行环境负责处理实际 API 调用。这对 Windows 桌面端 Web 技术开发者来说是一个重大利好，大幅降低了调用系统能力的门槛。

_来源：[i-programmer.info](https://www.i-programmer.info/) | [IT之家](https://so.html5.qq.com/page/real/search_news?docid=70000021_2196a68835017052)_

## CSS 生态

### CSS 新属性 text-fit 登场：轻松实现响应式 ASCII 艺术

CSS-Tip 网站发布教程，介绍利用新的 CSS `text-fit` 属性轻松实现响应式 ASCII 艺术。这个新属性允许文本内容根据容器尺寸自动缩放适配，在纯 CSS 领域开辟了创意排版的新可能。同站还介绍了 CSS `border-shape` 属性实现多形状变体、`background-clip` 新增值以及纯 CSS 节点连接图等近期 CSS 新特性，显示出 2026 年 CSS 标准仍在持续进化。

_来源：[CSS Tip](https://css-tip.com/ascii-art/)_

## 前端框架

### WordPress 7.1 继续采用 React 18.3，因 React 19 兼容性问题

WordPress 开发团队宣布，由于兼容性问题，React 19 将不会被纳入 WordPress 7.1 版本，该版本将继续采用 React 18.3。团队曾在 Gutenberg 插件中短暂启用 React 19 进行测试，但发现新版 React 可能带来各种兼容性问题。这一决定对大量依赖 WordPress 的生态开发者影响深远，也反映出主流 CMS 在大版本框架升级上的谨慎态度。

_来源：[IT之家](https://so.html5.qq.com/page/real/search_news?docid=70000021_7256a671eff69052)_

### CanIUseRSCs：跟踪 React Server Components 跨框架支持情况的工具上线

开发者 Krasimir 发布了一个名为 CanIUseRSCs 的工具（灵感来源于 CanIUse），专门跟踪 React Server Components 在不同框架和库中的支持情况。随着 RSC 逐渐成为全栈 React 开发的核心模式，这个工具可帮助开发者在 Next.js、Remix、Astro 等框架之间做技术选型时快速确认 RSC 兼容性。

_来源：[GitHub - krasimir/CanIUseRSCs](https://github.com/krasimir/CanIUseRSCs/)_

## 跨端开发

### HarmonyOS 7 确认 7 月内亮相：100% 全栈自研纯血鸿蒙

华为终端 BG CEO 何刚透露，即将到来的 HarmonyOS 7 在空间感和沉浸式交互上有不少新升级，很快与大家见面。HarmonyOS 7 是鸿蒙系统首次实现 100% 全栈自研的「纯血鸿蒙」版本，彻底移除安卓 AOSP 兼容层，不再支持 APK 格式应用，仅运行鸿蒙原生 HAP 应用。系统深度集成盘古大模型 6.0，依托麒麟芯片 NPU 实现本地化 AI 运算。其对前端开发者意味着 ArkUI（基于 TypeScript 的声明式 UI 框架）将成为鸿蒙应用开发的核心技术栈，并催生更多跨端适配需求。

_来源：[CNMO科技 via 腾讯新闻](https://so.html5.qq.com/page/real/search_news?docid=70000021_5266a62dbf375552)_

## AI 与前端

### Claude Code 已整合 Rust 重构版 Bun，启动速度提升 10%

开发者 Simon Willison 发现，6 月发布的 Claude Code v2.1.181 已整合 Rust 语言重构的 Bun（v1.4.0），在 Linux 平台上启动速度快 10%。此前 Bun 的创建者 Jarred Sumner 在 Claude Fable 5 的辅助下，耗时 11 天、花费 16.5 万美元，将 Bun 运行时从 Zig 完全重写为 Rust。Claude Code 底层使用 Bun 作为运行环境，这次整合意味着 AI 编程工具链正在与新一代 JS 运行时深度绑定。

_来源：[IT之家 / 腾讯新闻](https://news.qq.com/rain/a/20260724A08CMD00)_
