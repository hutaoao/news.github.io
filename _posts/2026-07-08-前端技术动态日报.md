今日前端圈动态丰富，从TypeScript Go重写版RC到工信部重磅预警、Google官方调试工具开源等，值得关注。

### TypeScript 7.0 RC 发布：Go 重写编译器带来 10 倍性能提升

微软于 7 月 7 日推出 TypeScript 7.0 RC 版本，这是 TypeScript 自 2012 年诞生以来最重大的底层重构。编译器完整迁移至 Go 语言，借助原生代码速度与共享内存并行处理，编译和类型检查速度相比 6.0 平均提升约 10 倍。开发者可通过 npm install -D typescript 安装体验，微软还在同一周内快速推进正式版发布。为便于过渡，微软提供了 @typescript/typescript6 兼容包，使 7.0 与 6.0 可并行安装。

_来源：[IT之家](https://new.qq.com/rain/a/20260707A0A24R00)_

### 工信部发布风险提示：Claude Code 存在安全后门隐患

7 月 8 日，工信部网络安全威胁和漏洞信息共享平台（NVDB）发布关于防范 AI 编程工具 Claude Code 安全后门隐患的风险提示。监测发现 Claude Code 内置监控机制，会在未经用户同意的情况下向远程服务器回传用户地域、身份标识等敏感信息，受影响版本为 2.1.91 至 2.1.196。此前，阿里巴巴已于 7 月 3 日内部通知全员禁用 Claude 全系产品，Anthropic 回应称该机制系防止账户转售和模型蒸馏的实验性措施，已于 7 月 2 日新版本中移除。此事引发了对 AI 编程工具安全合规的广泛讨论。

_来源：[观点网](https://new.qq.com/rain/a/20260708A00A9U00) | [CSDN分析](https://blog.csdn.net/CHAM_GJ/article/details/162520789)_

### Chrome DevTools MCP 开源：AI 编码助手可直接操控浏览器

Google Chrome DevTools 团队开源了 Chrome DevTools MCP，通过 Model Context Protocol 协议让 Claude、Cursor、Copilot 等 AI 编程助手直接操控和检查实时运行的 Chrome 浏览器实例。它提供完整的 DevTools 能力，包括页面导航、性能分析、网络请求检查、内存调试等，不仅仅是浏览器自动化工具，而是将专业调试能力以标准化方式暴露给 AI 代理。项目支持自动连接、URL 连接和 WebSocket 端点连接等多种方式，已迅速成为前端 AI 调试的热门工具。

_来源：[GitHub - ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) | [Dashen Tech](https://dashen-tech.com/)_

### ECMAScript 2026 正式获批：JavaScript 迎来第 17 版规范

ECMA International 于 6 月 30 日正式批准 ECMAScript 2026，这是 JavaScript 规范的第 17 个版本。新增内容包括：Math.sumPrecise 方法（高精度求和）、Iterator.concat（连接多个迭代器）、Array.fromAsync（从异步可迭代对象构建数组）、Error.isError（识别错误对象）、Map/WeakMap 默认值方法、Uint8Array 与 Base64/十六进制互转、JSON.parse reviver 增强参数及 JSON.rawJSON 方法等。这些特性进一步完善了 JS 在数值计算、异步数据处理和编码转换等场景的能力。

_来源：[至顶科技](https://new.qq.com/rain/a/20260710A002R500) | [W3Schools](https://www.w3schools.com/jS/js_2026.asp)_

### Chrome 151 Dev 更新：CSS 锚点定位增强与新伪元素

Google Chrome 最新 Dev 版本在 CSS 方面带来多项重要更新：CSS 锚点定位增强，anchor() 函数现已可解析已转换元素的边界框；新增 ::search-text 伪元素，支持自定义查找结果的前景/背景颜色和文字装饰；@scroll-state 支持根据滚动方向设置样式，可实现导航栏上滑显现、下滑隐藏等效果。与此同时，CSS Tip 报导 background-clip 属性也正迎来新值升级，进一步增强 Web 开发者对背景渲染的控制力。

_来源：[爱纯净](http://www.aichunjing.com/soft/2018-09-06/312.html) | [CSS Tip](https://css-tip.com/)_
